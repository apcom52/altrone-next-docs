## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Documentation search

MiniSearch indexes the documentation Markdown at build time. The generated
`/en/search-index.json` and `/ru/search-index.json` routes are static assets;
search runs entirely in the browser and loads the current locale’s index on demand.
Navigation determines page URLs, including component tabs. Missing translations
use the same English fallback as the documentation renderer.

Run `npm run test:search` to verify indexing, API queries, typo tolerance and anchors.
