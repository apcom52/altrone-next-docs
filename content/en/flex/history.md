# Flex

:::release[Altrone 4 Decent Dragon]{icon="/logos/altrone-4.png" logo="Flex" name="Flex" open="true"}
**4.0**

- New design.
- Added unified gap sizes between children (`gap`).
- `direction` is renamed to `orientation`.
- `tagName` is replaced with `asChild`.
- `align` now uses the shared `Align` type.
:::

:::release[Altrone 3 Curious CatZilla]{icon="/logos/altrone-3.png" image="/logos/flex-3.png" name="Flex"}
**3.0**

- New design.
- `Flex` is added to the library in place of `ButtonContainer`: a primitive for laying out elements in a row or a column.
:::

:::release[Altrone 2 Blind Basilisk]{icon="/logos/altrone-2.png" image="/logos/flex-2.png" name="ButtonContainer"}
**2.0**

- No API changes.
:::

:::release[Altrone 1 Angry Acromantula]{icon="/logos/altrone-1.png" image="/logos/flex-1.png" name="ButtonContainer"}
**1.0**

- `ButtonContainer` is added to the library: a container for placing buttons in a row or a column.
