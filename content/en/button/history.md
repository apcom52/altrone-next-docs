# Button

:::release[Altrone 4 Decent Dragon]{icon="/logos/altrone-4.png" logo="Button" name="Button" open="true"}
**4.0**

- `Button` got a new design.
- The button variants are reworked and tied to meaning: `default`, `submit` and `text`.
- Added a success/failure animation.
- Added a built-in tooltip.
- `label` is now required.
- Added the `selected` state.
- New press animations. The old rainbow effect is removed.
:::

:::release[Altrone 3 Curious CatZilla]{icon="/logos/altrone-3.png" image="/logos/button-3.png" name="Button"}
**3.4**

- Added `badge`, with new CSS variables for it.

**3.3**

- The disabled button has a new look and its own CSS variables.

**3.1**

- The `role` prop is deprecated because it conflicts with ARIA. Use `severity` for the visual style and `ariaRole` to set the role explicitly.
- Added `showLabel`.

**3.0**

- `Button` got a new design.
- Added the rainbow hover effect (`rainbowEffect`).
:::
