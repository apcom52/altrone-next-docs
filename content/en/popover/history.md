# Popover

:::release[Altrone 4 Decent Dragon]{icon="/logos/altrone-4.png" logo="Popover" name="Popover" open="true"}
**4.0**

- New design.
- New entrance animation.
- Improved positioning.
- Added a mode that covers the trigger instead of sitting beside it (`overlap`).
- Removed the built-in arrow.
- `ref` now points to the trigger's DOM element.
- The imperative API (`show`/`hide`, previously `openPopup`/`closePopup`) moved to `controlRef`.
- Added a full controlled mode via `open`/`onOpenChange`.
:::

:::release[Altrone 3 Curious CatZilla]{icon="/logos/altrone-3.png" image="/logos/popover-3.png" name="Popover"}
**3.5**

- Fixed incorrect `children`/`content` types for certain cases.

**3.0**

- New design.
- `Popover` replaced `FloatingBox`: added a header title, a close button, focus management, trigger type selection, and a more modern positioning library.
- Fixed the child element being unreachable by focus.
:::
