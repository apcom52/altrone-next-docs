- Removed the `--photoViewerLoadingBackgroundColor` CSS variable. To change the loading background, override the common glass surface variables.

**3.3**

- Fixed the gallery showing the wrong image.

**3.0**

- `PhotoViewer` got a new design.

**2.2**

- Added the `openDescriptionByDefault` option to Altrone Options: image descriptions are expanded by default.

**2.1**

- Added the `min` and `max` props that limit how far an image can be zoomed.
- Fixed the toolbar overlapping the image when the description is expanded.

**2.0**

- `PhotoViewer` is added to the library. It shows a gallery of images: switch between them, zoom in and move the photo around the screen, with a title and description for each image.
