Two weeks ago the first beta version of the new Altrone was released — with a new live design, reimagined components, and improved accessibility. Beta 2 builds on that: we've worked on unifying the component API, refining functionality, and fixing bugs.

The API unification brings a major change to component prop names, how they behave, and even component names themselves — all changed to make migration from other libraries easier, bring everything to a single standard, and simplify understanding of the Altrone concept overall. This is a fairly large refactor, but a necessary one to make future versions of the library more flexible for new features.

Beta 2 continues preparing the library for the major release. It is not a stable version — bugs are possible that could break your application. Use this version only for testing and internal development.

- **General changes.** Added exports for all public component types, removed `renderFunc` from all remaining components (use `asChild` instead), removed the unnecessary `between` variant from the `Align` type, and many other typing fixes.
- **Application.** The list of supported languages has grown to eight — added Simplified Chinese, Portuguese, and Turkish, and fixed the incorrect German/Spanish codes (`ge`/`sp` → `de`/`es`). A new `icons` prop was added — you can now override the built-in lucide icons across all library components at once, instead of living with the system glyph set inside a design where you'd rather use a third-party icon set.
- **Screen.** `Screen.Sidebar` and `Screen.Aside` now support controlled mode, and the sidebar toggle button in the header (`Toolbar.SidebarToggleAction`) now binds to the sidebar automatically — without a single line of state on the developer's side. The header got a `fixed` prop: you can now return it to normal document flow if it shouldn't stay above content while scrolling. Also fixed bugs with header positioning and broken `Screen.Aside` collapsing.
- **Box.** Reworked design of the `glass` material — now a genuinely matte, dense surface regardless of `tone`/`color`. The diagonal `hatch` pattern has been reimagined into a neat dotted pattern and renamed to `dotted`. A new `pale` material was added — the same tint as `translucent`, but fully opaque, for surfaces that shouldn't blend with what's behind them.
- **Grid.** The `tagName` prop was replaced with `asChild` — now the only way to change the root element of `Grid`/`Grid.Column`, consistent with the rest of the library.
- **Flex.** `direction` renamed to `orientation`, and `tagName` to `asChild`, following the library-wide convention.
- **Drawer.** The Drawer moved to a new internal foundation (`Sheet`), shared with `Modal` — invisible from the outside, but it brought page scroll locking and protection from the iOS keyboard covering the panel. Opening is now controlled only via `open`/`onClose` — the trigger prop in `children` was removed. Added `dismissible` (disables closing by backdrop click and `Esc`, with a slight panel shake instead) and `showCloseButton`. Actions now go through the `actions` / `additionalActions` props; the imperative control method was renamed (`close` → `hide`), plus small design changes.
- **Popover.** `ref` now correctly points to the trigger's DOM element, and the whole imperative API (`show`/`hide`, formerly `openPopup`/`closePopup`) moved to a separate `controlRef` — the same way `Splitter` already worked. A true controlled mode was added — `open`/`onOpenChange`.
- **Dropdown.** `Dropdown.Menu` can now constrain and scroll a long list itself via the new `maxHeight` prop, without manually wrapping it in `Scrollable`.
- **Tooltip.** Got a proper set of control props: `trigger` chooses how it opens — hover, focus, or click — while `defaultOpen`/`onOpenChange` expose its state externally. `childrenClassName` renamed to `triggerClassName`.
- **Modal.** The Modal moved to the same `Sheet` foundation as `Drawer` — bringing with it a unified smooth slide-in animation for the whole family. Opening is entirely controlled via the `open` prop instead of a `children` click trigger. Added `showCloseButton` — you can hide the close icon and leave closing only to explicit footer actions. `leftActions` renamed to `additionalActions`. Scrolling long content now also works with the cursor over the backdrop, not just over the panel itself.
- **Scrollable.** Now powers scrolling not just in the usual places, but also in `Modal`/`Drawer`, `Splitter.Panel`, and `Dropdown.Menu` — one unified thin scrollbar across the whole library instead of native scrollbars showing up here and there. Added `controlRef` for access to the actual scrolling element. Fixed a bug where `maxHeight` was ignored and content leaked outside the container.
- **Form.** `size`/`disabled` now propagate from `Form` to all library controls — previously this only worked for `TextInput`-based fields, while `Select`, `Checkbox`, `Switch`, `Radio`, `ColorPicker`, `DatePicker`, `Slider`, and `FilePicker` simply didn't read the form context.
- **Splitter.** Added a controlled mode for panel sizes — `sizes`/`onSizesChange`, and `Splitter.Panel` now finally accepts `ref`/`className`/`style`, so the panel itself can be styled directly without an extra wrapper. `min`/`max` renamed to `minSize`/`maxSize`, and the resize handle's touch area was expanded.
- **Spoiler.** Got a true controlled mode — `open`/`onToggle`, and `openedByDefault` was renamed to `defaultOpen`.
- **Toolbar.** The main addition — actions that don't fit in the toolbar now neatly collapse into an overflow menu, with controllable `priority` for each action or group. `Toolbar.placement` renamed to `edge`. Removed three narrowly-specialized header actions — `BackAction`, `BackForwardAction`, `SearchAction`. Strengthened the blur on the `solid` variant; `Toolbar.Title.label` renamed to `title`.
- **Button.** The `selected` state is now noticeably more visible — instead of an almost transparent fill it now uses the opaque `pale` material. Button width can no longer be smaller than its height.
- **TextInput.** `className`/`style`/`ref` now point to the field's root element, as with all other components, rather than the hidden inner `<input>` — a separate `inputClassName`/`inputStyle` pair now exists for the input itself. Removed viewport zoom on focus on iOS for size `m`. The `shape` prop was removed — the wrapper is always a capsule now.
- **PasswordInput**, **NumberInput**, **AutocompleteInput**, **Search**. All changes from **TextInput** apply here too.
- **TextArea.** Renamed from `Textarea` to proper camelCase. All changes from **TextInput** apply here too.
- **Select.** Clicking an option no longer loses the original click/`Enter` event. The cursor over the field is now always a "hand" rather than a text cursor, as befits a non-editable field. `clearValue` renamed to `clear`; supports form context (`size`/`disabled`).
- **Checkbox.** `onChange` is now required; also now reads `size`/`disabled`/`name` from `Form`.
- **Switch.** Renamed from `Switcher`. All changes from **Checkbox** apply here too.
- **Radio.** `direction` renamed to `orientation`. `value` can now be omitted — a group can be rendered with no option selected. Reads form context.
- **ColorPicker.** The popup now has a title, and the footer has a persistent "Clear"/"Apply" action block instead of implicit closing via outside click. Minor design changes.
- **DatePicker.** The field's value now finally changes along with the app language — previously the date in the field always stayed in English no matter what you chose in `Application.language`. The "Today"/"This month"/"This year" button is now disabled if the result would fall outside `minDate`/`maxDate`; cursor is now "hand"; reads `disabled` from the form.
- **FilePicker.** A `disabled` prop was added — it didn't exist before at all.
- **Slider.** Renamed from `Range` to `Slider`. The `fill` variant is now always capsule-shaped. Fixed positioning of the current-value tooltip; props renamed `direction` → `orientation` and `onValueCommit` → `onChangeEnd`; also fixed slider behavior (the page no longer scrolls along with the thumb on touch devices; releasing the thumb over another element no longer triggers that element's click). Reads form context.
- **Calendar.** Fixed a bug where the weekend day color was overriding the disabled-date style.
- **DataTable.** Arguably the most packed release: the table now has a controlled mode for page, sorting, and filters — state can now be synced with the URL or any external store. The header now uses `Toolbar`, and `actions` can be arranged into leading, center, and trailing sections. Wide tables no longer stretch the page and instead get their own horizontal scroll with a synchronously scrolling header; table corner rounding was increased. The new `getRowId` prop finally removes the risk of row actions firing on the wrong row when data is rearranged externally. Removed the first/last page buttons from pagination; fixed header display during horizontal scrolling; expanded the column resize handle's touch area; scrolling moved to `Scrollable`; `onPageChange`/`onSortChange`/`onFilterChange`/`onModeChange` handlers now receive the native event.
- **Dialogs.** The cancel button in `showConfirm` renamed `rejectText` → `cancelText`. Dialogs close with an animation again instead of disappearing instantly.
- **Message.** `header` renamed to `title`.
- **Progress.** `children` renamed to `label`.
- **Tags.** Added a `size` prop.
- **Notifications.** The `useNotifications()` hook was removed — toasts and notifications are now invoked via plain functions `showToast`/`showNotification`/`dismissNotification`, callable from anywhere, even from a store action. Three separate positioning props (`toastPlacement`/`notificationSide`/`notificationPlacement`) were collapsed into a single corner-based `notificationPlacement`. Improved animation. Minor design changes.
- **Result.** `description` removed — the only way to pass description text now is `children`, as with `Message`.
- **NavigationList.** `GroupAction` and `LinkAction` removed — replaced by an `actions` prop on `Group`/`Link`, where you can put a regular button. Long labels and titles no longer overflow the sidebar.
- **BottomNavigation.**, **SideNavigation.** The `Item` subcomponent renamed to `Link`.
- **Tabs.** Added a `size` prop.
- **Breadcrumbs.** A custom root element via `asChild` no longer loses its `className`/`style` — previously they were completely overwritten.
- **Pagination.** Added an uncontrolled mode — `defaultPage`; `currentPage`/`onChange` are now optional. Added a `size` prop.
- **Avatar.** Fixed a component positioning bug.
- **Divider.** `direction` renamed to `orientation`.
- **Label.** The component now uses `Box`. `rounding` renamed to `shape`.
- **Loading.** Added a `value` prop — with it, the spinner stops spinning infinitely and instead draws a static arc based on percentage completion.
