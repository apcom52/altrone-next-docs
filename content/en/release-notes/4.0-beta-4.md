This beta release brings Altrone 4 one step closer to its official launch. We continue to focus on reliability and quality: we've fixed even more bugs, including issues affecting mobile devices, refined existing features, improved type definitions, and polished the appearance and behavior of components. Every detail is now more refined and consistent.

We've also paid special attention to accessibility. Keyboard navigation is now significantly more convenient: interactive elements receive focus correctly, and navigation and interactions behave as users expect. This makes your interfaces more accessible and comfortable for everyone, including those who rely on keyboards and assistive technologies.

---

Here's the complete list of changes included in this release:

**Application.** Fixed several issues affecting mobile devices.

**Screen.** Improved safe area handling and scrolling behavior on iOS.

**Drawer.** No longer conflicts with `Modal` and `Dialog`. Improved scrolling and focus management on mobile devices.

**Popover.** Fixed behavior issues on mobile devices.

**Dropdown.** Menu height is now constrained by the available space, preventing it from extending behind the on-screen keyboard on mobile devices. Improved animations when selecting menu items.

**Tooltip.** Fixed behavior issues on mobile devices.

**Modal.** Fixed behavior issues on mobile devices.

**AutocompleteInput.** Native browser autocomplete is now disabled by default.

**Search.** Fixed placeholder alignment.

**Select.** Searchable variants now open the keyboard on the first tap on iOS.

**Checkbox, Switch, Radio.** Fixed visual inconsistencies.

**DataTable.** Fixed table content clipping.

**Message.** Improved alignment of message elements.

**Notifications.** Improved behavior on mobile devices.

**Tabs.** Refined tab design.
