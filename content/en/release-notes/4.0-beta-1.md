**Altrone is back!**

After a long process of reworking and rethinking, we've arrived at a completely new Altrone — but still recognizable.

The previous major version brought a lot of useful changes to Altrone: a unified design system, subcomponents, improved typography, reworked popover logic, and much more.

This update brings a completely new design that incorporates all the current trends in app design. Components now fit together perfectly, so you can assemble truly impressive interfaces from them. We've put a lot of work into accessibility, touch-device usability, and flexibility for a wide range of tasks. The Screen component alone offers so many possibilities for quickly building app layouts for any scenario!

Almost all components, besides the new design, have rethought their place in the overall concept and gained new features. Some outdated components (Configuration, Icon, List, PhotoViewer, TopNavigation) have been removed. Others (DummyBox, Empty) have also disappeared, but their idea lives on inside other components. And, of course, there are brand-new components — Screen, Box, Image, Drawer, Splitter, Dialogs, Result, Label, and Skeleton.

Beta 1 means most of the work on the next version is already done. No major global changes are planned, though a couple of significant refinements may still happen. Over the next few weeks, other beta versions will come out with refinements and stability improvements. A stable release is planned for the end of October.

- **Application.** As before, this is the starting point of any Altrone app. Settings are still stored here, except instead of `config` they're now passed directly as props. You no longer need to wrap parts of the app in `Configuration` — use CSS variable overrides instead.
- **Screen.** A fresh element that lets you build complex app layouts — with a header, a collapsible sidebar, a footer, navigation, or a side column, and with adaptation to different devices. The ability to build layouts manually is still there — `Screen` remains very flexible.
- **Text.** We removed all subcomponents here — which noticeably simplified working with typography in apps. In their place, a large set of discriminating props now handles rendering the right text. We also expanded the size scale, added text truncation, and new capabilities for links.
- **Box.** A newcomer to the family — a building block for the whole interface. With it you can place a block on the page, setting its material, shape, spacing, and various kinds of interactivity.
- **Image.** Another debutant — needed for adding an image to the page. An image can be accompanied by a caption.
- **Grid.** Improved the column-size calculation formula, added row and column gaps, and fixed the logic for wrapping columns onto a new row.
- **Flex.** Unified spacing sizes between child elements were added.
- **Drawer.** A new component that draws a sliding panel — from the left or right. A handy tool for cards used to create, edit, or view large amounts of data. `Drawer` has built-in mechanisms for headers with action buttons.
- **Popover.** Besides a new, striking appearance animation, we improved positioning, added a mode for displaying over the source component, removed the built-in arrow, and made a number of other improvements you'll definitely appreciate.
- **Dropdown.** In addition to all of `Popover`'s innovations, `Dropdown` got a refined API and native event objects in callbacks.
- **Tooltip.** Tooltips shed many of `Popover`'s features — they were simply excessive for tooltips. Instead, they gained features specific to tooltips: you can now specify a title and a keyboard shortcut.
- **Modal.** Changed the component's behavior: you no longer need to wrap the source button in the modal to attach an open event to it — we went back to how it worked in Altrone 2.
- **Scrollable.** Switched to OverlayScrollbars as the engine for scrollable areas, updated the scrollbar design, and added new properties.
- **CollapsedList** got a visual refresh and slightly changed behavior for the line-spacing property.
- **Form.** Besides a small visual refresh, improved handling of error messages.
- **Splitter.** A powerful newcomer — lets you place several panels on screen with the ability to resize them vertically and horizontally. Flexible configuration lets you set minimum and maximum sizes, enable collapsing, and more.
- **Spoiler.** You can now track state changes via a new callback, and content appearance/hiding is now animated.
- **Toolbar.** A very major update — the component went from relatively simple to a ready-made building block for the app header, as well as for toolsets elsewhere in the interface. Added different display variants, the ability to place the toolbar on any of the four sides of the screen, and several sizes. New subcomponents let you add a title, group actions, and set group alignment. And `Action` is now a full-fledged button with all its new capabilities.
- **Button.** Heavily reworked button variants — now tied to semantics (regular, `submit`, or text). Improved states: besides loading, there's now a success/failure animation, a built-in tooltip was added, `label` was made required, and many other fixes.
- **TextInput.** Besides an updated field design, seriously reworked the dynamic islands: more precise positioning calculations, full-fledged buttons used in action islands, and an island added with a character counter.
- **PasswordInput.** Got a new design and all of `TextInput`'s other innovations.
- **NumberInput.** Inherited all of `TextInput`'s updates, and also dropped the default `Stepper` as unnecessary.
- **AutocompleteInput.** Expanded typing capabilities and gained new options for building the suggestions list.
- **Search.** Updated design plus all of `TextInput` and `AutocompleteInput`'s innovations.
- **Textarea.** New design and support for dynamic islands.
- **Checkbox, Switcher, Radio.** These components got a new design, the ability to change size, and stricter typing.
- **DatePicker.** A new callback for `RangePicker`, the ability to override the control, and an event object in `onChange`.
- **ColorPicker.** Improvements to control overriding and an event object in `onChange`.
- **FilePicker.** Became controlled — you can now pass `value` and `onChange`, set a placeholder, and other parameters.
- **Range.** A classic range variant appeared, plus typing and callback improvements.
- **Select.** A new way to override the component, improved typing, and an event object in callbacks.
- **Calendar.** Gained a full-fledged design — with date highlighting, a header, and navigation. Works in one of three modes: single-day, multi-day, or date-range selection. Locale settings are automatically picked up from the app's current locale. Additional date-display customization options were added.
- **DataTable.** New rendering engine — TanStack Table. You can now set a column type, which affects cell rendering and filtering. The table supports a data-loading mode, column resizing, and new filtering options.
- **Dialogs.** Ready-made modal window layouts for the most popular user-interaction scenarios — an informational message, choosing one of two options, and entering a value.
- **Message** got an updated design and improved accessibility.
- **Progress.** You can now specify a minimum value.
- **Tags.** You can now override the control for each tag individually.
- **Result.** A new component for showing feedback to the user in the center of a block — messages about a successful operation, an error, no access, empty content, and so on.
- **Notifications.** A completely new in-app notification engine. Unified positioning settings for toasts and notifications. You can add an image to a notification, configure display time, and set the closing condition.
- **NavigationList.** Gained the ability to add fixed headers and footers for navigation, and menu-item controls are now easily overridden.
- **BottomNavigation.** Learned to become fixed on screen, got a dynamic backdrop for the active item, and simple control overriding.
- **SideNavigation.** Improved list semantics.
- **Tabs.** A return to the classic Altrone 2 design, locked tabs, and improved control overriding.
- **Breadcrumbs.** Improved accessibility and control overriding.
- **Pagination.** A completely rethought control — instead of buttons and an input field, it's now a classic strip design with page numbers. You can hide navigation buttons and configure the number of visible pages.
- **Avatar.** You can now set the background color and text color separately.
- **Loading.** Now also accepts a number as the size.
- **CloseButton.** New design and improved accessibility.
- **Label.** A new compact component for displaying text labels in the interface. Supports different colors and shapes.
- **Skeleton.** A new component, key for creating animated layouts while the app is in a loading state.
