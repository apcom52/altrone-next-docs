In this update, **Slider** and **Splitter** no longer get stuck in a dragging state when a drag is cancelled. **Splitter** restores the last confirmed panel sizes, and **Slider** passes the final drag value to `onChangeEnd` on release, even if `value` hasn’t updated yet. A single **Toolbar** region now spans the full available width or height, so actions move into the overflow menu only when they run out of room.
