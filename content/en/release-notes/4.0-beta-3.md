The new beta of Altrone 4 continues our push to refine functionality and fix bugs. This version fixes several bugs that could appear on mobile devices, corrects styling issues on some devices, improves focus states and accessibility of some components, and adds a few new features.

This is an unstable version. Errors may occur that could break your application. Use it only for testing and internal development.

- **Application.** It now manages the tab title itself: just pass `applicationName`, and `document.title` will be built from the name of the active `Screen` and the application. If you need to override the title at a specific moment, use the `setPageTitle` and `resetPageTitle` functions, which work from anywhere, even outside React. A large number of focus-style issues were fixed across many components. A new utility component, `Override`, was added to change the theme, accent, language, labels, and icons for a specific part of the interface.
- **Screen.** `Sidebar` now behaves symmetrically: a sidebar that was hidden on a narrow screen returns to its place when the screen becomes wide again. Other sidebar display issues were fixed.
- **Box.** Some default styles were removed from native `<button>`, `<a>`, `<input>`, and other elements passed via `asChild`.
- **Text.** Italic (`italic`) is now rendered with true italic fonts.
- **Image.** The image looks calmer: it keeps only a thin border without a shadow, and the caption is set in italics.
- **TextInput.** Horizontal padding now scales smoothly with the field size, and `readonly` no longer has a background color or other unnecessary styles.
- **AutocompleteInput.** A custom `onKeyDown` no longer breaks the built-in behavior: `Escape` and selection with `Enter` keep working.
- **Search.** The suggestions popup no longer opens when `getSuggestions` is not provided.
- **Switch.** Incorrect focus styles were fixed.
- **FilePicker.** Upload progress in the file chip no longer breaks the component's rendering.
- **DatePicker.** Opening the calendar no longer scrolls the page to the top of the document.
- **DataTable.** The table is now more accessible: it is marked up with roles, sortable columns are keyboard-accessible and announce the sort direction to screen readers. Filters now show readable column names instead of technical identifiers. The "Filters" button no longer appears if there are no filterable columns.
- **NavigationList.** The display of parent items for a selected link was improved. A small gap was added between items, and the background of nested items now matches the size of their content.
- **BottomNavigation.** Links can now be focused and activated from the keyboard (`Enter`/`Space`).
- **Avatar.** A new `icon` prop lets you represent a user with an icon instead of initials. First and last names are now optional, so an icon-only avatar doesn't need made-up data.
- **Label.** Added an `icon` prop and a new `status` variant: a pale fill, a border, and a colored dot that can hold a status icon.
