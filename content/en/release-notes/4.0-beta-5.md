This is the last beta of the new Altrone 4 before the release. In it, we fix another batch of critical bugs, improve the accessibility of several components and polish the design.

---

Here's the full list of changes in this release:

**Dropdown.** Better keyboard accessibility: a submenu opens with `→` or `Enter`, while `←` and `Escape` close only that submenu and return focus to its parent item without collapsing the whole chain. The background highlight of the active menu item is fixed as well.

**Tooltip.** Fixed animation behavior under reduced motion.

**Modal.** Fixed the animation when several windows are opened in a row.

**Spoiler.** Fixed animation behavior under reduced motion.

**Toolbar.** A group collapses into the overflow menu only if it contains nothing but actions — search, inputs and custom elements no longer disappear from the toolbar. `SidebarToggleAction` now moves into the menu too and toggles the sidebar from there.

**Button.** The `mini` size gets an invisible 24px hit area, making small buttons easier to tap.

**NumberInput.** The field now behaves as expected: `min` no longer gets in the way of typing (the value is clamped to the range on blur), negative numbers can be entered when `min` isn't set, and a cleared field reports `undefined` instead of `0` and doesn't refill itself.

**ColorPicker.** Full keyboard support: focus is trapped inside the popup, `Esc` returns it to the field, presets can be navigated with arrow keys, and hex and RGB values are applied with `Enter`. The palette handles are now round and get a clearly visible focus ring.

**FilePicker.** More robust error handling: a file is removed from the list even if `DELETE` fails, and in single mode a failed deletion of the old file no longer cancels the new selection. Without `url`, no built-in requests are sent, while `autoUploadFn`/`removeFileFn` keep working.

**DataTable.** `link` columns are filtered by text, and columns without filtering rules no longer appear in the "Add filter" menu.

**Dialogs.** A new `showAlert`/`showConfirm`/`showPrompt` opens only after the current one closes instead of replacing it, and every promise resolves in order.

**Label.** New `orange` and `green` colors, and the radius, gap and typography can now be overridden with CSS variables. With `size="mini"` and `variant="status"`, the dot no longer touches the border.

**Loading.** `size` accepts any CSS unit, the color can be set via `style`, and reduced motion doesn't stop the animation.

**Skeleton.** Without an explicit height it takes the height of a line of text, and without `radius` it is rounded like `Box`. Sizes accept numbers, and `maxWidth`/`maxHeight` work together with `width`/`height`. `className` no longer overrides the component's own classes.

**CloseButton.** The close icon can now be overridden.
