# TextInput

:::release[Altrone 4 Decent Dragon]{icon="/logos/altrone-4.png" logo="TextInput" name="TextInput" open="true"}
**4.0**

- New design.
- The dynamic islands were reworked: more accurate positioning, full-fledged buttons in action islands, and a new character counter island.
- `className`, `style` and `ref` now point to the root element; the `<input>` itself gets `inputClassName` and `inputStyle`.
- Removed the viewport zoom on focus in iOS Safari for the `m` size.
- Removed the `shape` prop: the wrapper is always a capsule.
:::
