# Splitter

Кнопки сворачивания и разворачивания на разделителе рисуют четыре направленных шеврона: влево и вправо для горизонтального `Splitter`, вверх и вниз для вертикального. Их можно заменить целым набором. Сама ручка перетаскивания — просто «таблетка», иконки у неё нет. Иконки, которые вы кладёте в содержимое панелей, описаны в [сведениях](/ru/components/layout/splitter).

:::spoiler[Как заменить иконки]
Передайте `icons` только с теми шевронами, которые хотите поменять, — остальные останутся по умолчанию. Один и тот же шеврон используется для обоих состояний кнопки: кнопка сворачивания левой панели смотрит влево, а когда панель свёрнута — вправо.

```tsx
import { ArrowLeft, ArrowRight } from "lucide-react";

<Splitter icons={{ chevronLeft: <ArrowLeft />, chevronRight: <ArrowRight /> }}>
  <Splitter.Panel collapsible>
    <Sidebar />
  </Splitter.Panel>
  <Splitter.Panel>
    <Content />
  </Splitter.Panel>
</Splitter>
```

::playground{src=splitter/SplitterIconsDemo caption="Наведите на разделитель, чтобы увидеть заменённые стрелки"}

Каждая иконка — любой `ReactElement`. Автоматический размер привязан к классу `lucide`, поэтому иконке из другой библиотеки нужен явный размер около `16px` — см. [Иконки](/ru/foundations/icons).
:::

## Иконки

::::icon-cards
:::icon-card[chevronLeft]{icon="ChevronLeft"}
Сворачивает левую панель или разворачивает свёрнутую правую в горизонтальном разбиении
:::

:::icon-card[chevronRight]{icon="ChevronRight"}
Сворачивает правую панель или разворачивает свёрнутую левую в горизонтальном разбиении
:::

:::icon-card[chevronUp]{icon="ChevronUp"}
Сворачивает верхнюю панель или разворачивает свёрнутую нижнюю в вертикальном разбиении
:::

:::icon-card[chevronDown]{icon="ChevronDown"}
Сворачивает нижнюю панель или разворачивает свёрнутую верхнюю в вертикальном разбиении
:::
::::
