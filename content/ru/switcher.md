# Switcher

Switcher — это переключатель мгновенного действия. В отличие от чекбокса, он не требует подтверждения: изменение состояния происходит сразу при нажатии. Используйте его тогда, когда пользователь ожидает немедленного эффекта — включить тёмную тему, разрешить уведомления, активировать функцию.

## Основное использование

::playground{src=SwitcherBasicDemo}

```tsx
const [enabled, setEnabled] = useState(false);

<Switcher checked={enabled} onChange={(v) => setEnabled(v)}>
  Тёмная тема
</Switcher>
```

API полностью совпадает с `Checkbox`. Дочерний текст — подпись рядом с переключателем.

## Опасное действие

`danger` используется, когда включение опции несёт риски: открытие публичного доступа, необратимые изменения конфигурации.

::playground{src=SwitcherDangerDemo}

```tsx
<Switcher checked={enabled} onChange={(v) => setEnabled(v)} danger>
  Публичный доступ к данным
</Switcher>
```

:::warning
Switcher с `danger` всё равно изменяет состояние немедленно. Если действие требует подтверждения — покажите диалог до изменения состояния, не после.
:::

## Недоступное состояние

::playground{src=SwitcherDisabledDemo}

```tsx
<Switcher disabled>Уведомления (недоступно)</Switcher>
<Switcher checked disabled>Автосохранение (недоступно, включено)</Switcher>
```

## Свойства

Switcher наследует все свойства `Checkbox`, за исключением `indeterminate` — у переключателя нет промежуточного состояния.

:::prop[checked]{type="boolean"}
Состояние переключателя. Управляется извне.
:::

:::prop[onChange]{type="(state: boolean, e: ChangeEvent) => void"}
Вызывается при переключении. Первый аргумент — новое значение `boolean`.
:::

:::prop[danger]{type="boolean" default="false"}
Красное цветовое оформление. Сигнализирует о рискованном действии.
:::

:::prop[disabled]{type="boolean" default="false"}
Блокирует взаимодействие.
:::

:::prop[name]{type="string"}
HTML-атрибут `name`. Нужен при использовании внутри `<form>`.
:::

:::prop[children]{type="ReactNode"}
Подпись рядом с переключателем.
:::

## Рекомендации

**Switcher — это не чекбокс.** Чекбокс фиксирует намерение (применить настройку при сохранении), Switcher применяет изменение немедленно. Смешивание этих паттернов на одном экране сбивает с толку.

**Подпись описывает эффект, а не действие.** «Тёмная тема» лучше, чем «Включить тёмную тему». Переключатель уже подразумевает включение — дублировать это в тексте не нужно.

**Не блокируйте без объяснения.** Если `disabled`, пользователь должен понимать почему. Добавьте `Tooltip` или текст рядом с недоступным переключателем.
