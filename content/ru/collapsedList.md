# CollapsedList

Информация занимает место — и не вся она одинаково важна. `CollapsedList` показывает первые несколько элементов и прячет остальные за кнопкой «Показать ещё». Пользователь видит ровно столько, сколько нужно для ориентации, и сам решает, нужно ли ему больше.

## Базовое использование

По умолчанию список показывает первые 5 элементов. Укажите `limit`, чтобы изменить это число.

```tsx
<CollapsedList limit={3} gap="xs">
  <div>Элемент 1</div>
  <div>Элемент 2</div>
  <div>Элемент 3</div>
  <div>Элемент 4</div>
  <div>Элемент 5</div>
</CollapsedList>
```

::playground{src=CollapsedListBasicDemo caption="Нажмите «Показать ещё», чтобы развернуть список"}

Если элементов не больше, чем `limit`, кнопка не появляется вовсе.

`limit` режет **прямых** потомков. Передавайте элементы списком (или одним массивом через `map`); если обернуть их в один элемент, список увидит одного потомка и резать будет нечего.

## Кастомная метка кнопки

По умолчанию используется локализованная метка. Если нужен более конкретный текст — передайте строку или функцию в `expandButtonLabel`. Функция получает контекст с числом скрытых элементов и текущим состоянием.

```tsx
<CollapsedList
  limit={3}
  expandButtonLabel={({ hiddenItems, expanded }) =>
    expanded ? "Скрыть отзывы" : `Показать ещё ${hiddenItems} отзыва`
  }
>
  {reviews.map(/* ... */)}
</CollapsedList>
```

::playground{src=CollapsedListCustomLabelDemo caption="Метка меняется в зависимости от состояния"}

## Одностороннее раскрытие

`hideExpandButtonAfterUsage` убирает кнопку после того, как список раскрыт. Используйте, когда возможность свернуть список обратно не нужна — например, в историях изменений или журналах.

```tsx
<CollapsedList limit={3} hideExpandButtonAfterUsage>
  {changelog.map(/* ... */)}
</CollapsedList>
```

::playground{src=CollapsedListOneWayDemo caption="После раскрытия кнопка исчезает"}

## Свойства

:::prop[limit]{type="number" default="5"}
Количество видимых элементов в свёрнутом состоянии.
:::

:::prop[gap]{type="Gap"}
Отступ между элементами. Использует шкалу отступов дизайн-системы: `xs`, `s`, `m`, `l`, `xl`.
:::

:::prop[hideExpandButtonAfterUsage]{type="boolean" default="false"}
При `true` кнопка исчезает после первого раскрытия. При `false` появляется кнопка сворачивания.
:::

:::prop[expandButtonLabel]{type="string | (ctx: CollapsedListContext) => string"}
Кастомная метка кнопки раскрытия. Функция получает `hiddenItems`, `totalItems` и `expanded`.
:::

## Рекомендации

**Подбирайте `limit` под контекст, а не под количество элементов.** Три элемента в превью карточки — правильно. Три элемента в длинной форме настроек — слишком мало. Ориентируйтесь на то, сколько пользователю достаточно для принятия решения.

**Называйте действие точно.** «Показать ещё» — нейтрально и понятно. «Показать ещё 7 тегов» — конкретно и честно. Пользователь знает, сколько усилий ему предстоит.

**Одностороннее раскрытие — для данных, которые не нужно прятать.** Если пользователь развернул список и вряд ли захочет вернуться к свёрнутому виду, используйте `hideExpandButtonAfterUsage`. Это упрощает интерфейс и убирает лишнее действие.

**Не используйте `CollapsedList` вместо виртуализации.** Компонент подходит для десятков элементов, а не для тысяч. Если список растёт до сотен строк — рассмотрите виртуальный список или пагинацию.
