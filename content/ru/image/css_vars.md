# Image

CSS-переменные, которые читает `Image` и которые можно переопределить.

:::spoiler[Как переопределять переменные]
Переменные `--image-*` определены на корне приложения, поэтому изменение в таблице стилей перекрашивает сразу все `Image`, а изменение на любом предке — картинки внутри него. Для одного изображения используйте проп `style`: он попадает на `<figure>`, а инлайновое значение перебивает любое значение из классов, в любой теме.

```tsx
<Image
  src="/missing.jpg"
  alt="Team photo"
  style={{ "--image-broken-media-size": "56px" } as React.CSSProperties}
/>
```

::playground{src=image/ImageCssVarsDemo caption="Более низкая рамка и крупная красная иконка замены"}

Что нельзя переопределить через переменную:

- **Ширину, высоту, радиус скругления, `fit` и `objectPosition`.** Компонент записывает их инлайн из пропов, поэтому используйте проп.
- **Кромку картинки.** Она читает `--border-a1` — глобальный токен; отдельной переменной у изображения нет.
- **Заглушку загрузки.** Это `Skeleton`, он настраивается своими переменными.
:::

## Внутренние переменные

Определены самим `Image`.

::::css-vars
:::css-var[--image-min-height]{kind="size" type="Размер"}
Минимальная высота рамки. По умолчанию: `200px`
:::

:::css-var[--image-broken-media-size]{kind="size" type="Размер"}
Диаметр круга за иконкой битого изображения. По умолчанию: `40px`
:::

:::css-var[--image-broken-icon-size]{kind="size" type="Размер"}
Размер иконки битого изображения. По умолчанию: `18px`
:::

:::css-var[--image-broken-media-background]{kind="fill" type="Цвет заливки" color="var(--interactive-1)"}
Заливка круга за иконкой. По умолчанию: `var(--interactive-1)`
:::

:::css-var[--image-broken-media-color]{kind="text" type="Цвет текста" color="var(--text-1)"}
Цвет иконки битого изображения. По умолчанию: `var(--text-1)`
:::
::::

## Глобальные переменные

Не определены `Image`: глобальные токены дизайна, которые он читает. Изменение токена перекрашивает сразу все `Image`. Подпись — это `Text`, а заглушка загрузки — `Skeleton`, поэтому их переменные тоже действуют.

::::css-vars
:::css-var[--radius-l]{kind="radius" type="Радиус скругления"}
Радиус скругления рамки, если не задан `radius`. По умолчанию: `12px`
:::

:::css-var[--border-a1]{kind="border" type="Цвет обводки" color="var(--border-a1)"}
Тонкая кромка картинки. По умолчанию: `var(--gray-a6)`
:::

:::css-var[--space-inline]{kind="gap" type="Размер отступа"}
Промежуток между рамкой и подписью. По умолчанию: `var(--s-gap)`
:::

:::css-var[--background-1]{kind="fill" type="Цвет заливки" color="var(--background-1)"}
Фон заглушки битого изображения. По умолчанию: `var(--gray-1)`
:::

:::css-var[--interactive-1]{kind="fill" type="Цвет заливки" color="var(--interactive-1)"}
Значение по умолчанию для круга за иконкой. По умолчанию: `var(--gray-3)`
:::

:::css-var[--text-1]{kind="text" type="Цвет текста" color="var(--text-1)"}
Значение по умолчанию для цвета иконки битого изображения. По умолчанию: `var(--gray-11)`
:::

:::css-var[--text-color-muted]{kind="text" type="Цвет текста" color="var(--text-color-muted)"}
Цвет подписи. По умолчанию: `var(--text-1)`
:::
::::
