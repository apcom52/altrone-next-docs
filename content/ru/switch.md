# Switch

Switch — это переключатель мгновенного действия. В отличие от чекбокса, он не требует подтверждения: изменение состояния происходит сразу при нажатии. Используйте его тогда, когда пользователь ожидает немедленного эффекта — включить тёмную тему, разрешить уведомления, активировать функцию.

## Основное использование

::playground{src=SwitchBasicDemo}

```tsx
const [enabled, setEnabled] = useState(false);

<Switch checked={enabled} onChange={(v) => setEnabled(v)}>
  Тёмная тема
</Switch>
```

API полностью совпадает с `Checkbox`. Дочерний текст — подпись рядом с переключателем.

## Опасное действие

`danger` используется, когда включение опции несёт риски: открытие публичного доступа, необратимые изменения конфигурации.

::playground{src=SwitchDangerDemo}

```tsx
<Switch checked={enabled} onChange={(v) => setEnabled(v)} danger>
  Публичный доступ к данным
</Switch>
```

:::warning
Switch с `danger` всё равно изменяет состояние немедленно. Если действие требует подтверждения — покажите диалог до изменения состояния, не после.
:::

## Недоступное состояние

::playground{src=SwitchDisabledDemo}

```tsx
<Switch disabled>Уведомления (недоступно)</Switch>
<Switch checked disabled>Автосохранение (недоступно, включено)</Switch>
```

## Размеры

`size` (`mini` / `s` / `m` / `l` / `xl`) масштабирует дорожку, ползунок и текст
подписи — за всё отвечает одно значение (высота дорожки), остальное выводится из него.
Кликабельная строка не становится ниже 24px.

```tsx
<Switch size="s" checked={on} onChange={setOn}>Компактно</Switch>
<Switch size="l" checked={on} onChange={setOn}>Крупно</Switch>
```

## Без подписи

Если `children` не передан, имя для скринридеров задаётся через `aria-label` — он
попадает на сам `<input>`, а не на обёртку.

```tsx
<Switch aria-label="Wi-Fi" checked={wifi} onChange={setWifi} />
```

## Свойства

Switch наследует все свойства `Checkbox`, за исключением `indeterminate` — у переключателя нет промежуточного состояния.

:::prop[checked]{type="boolean"}
Состояние переключателя. Управляется извне.
:::

:::prop[onChange]{type="(state: boolean, event: ChangeEvent<HTMLInputElement>) => void"}
Вызывается при переключении. Первый аргумент — новое значение `boolean`.
:::

:::prop[danger]{type="boolean" default="false"}
Красное цветовое оформление. Сигнализирует о рискованном действии.
:::

:::prop[disabled]{type="boolean" default="false"}
Блокирует взаимодействие (проставляется на нативный `<input>`).
:::

:::prop[size]{type="'mini' | 's' | 'm' | 'l' | 'xl'" default="'m'"}
Масштаб дорожки, ползунка и типографики подписи. Высота строки не опускается ниже 24px.
:::

:::prop[name]{type="string"}
HTML-атрибут `name`. Нужен при использовании внутри `<form>`.
:::

:::prop[children]{type="ReactNode"}
Подпись рядом с переключателем.
:::

## Рекомендации

**Switch — это не чекбокс.** Чекбокс фиксирует намерение (применить настройку при сохранении), Switch применяет изменение немедленно. Смешивание этих паттернов на одном экране сбивает с толку.

**Подпись описывает эффект, а не действие.** «Тёмная тема» лучше, чем «Включить тёмную тему». Переключатель уже подразумевает включение — дублировать это в тексте не нужно.

**Не блокируйте без объяснения.** Если `disabled`, пользователь должен понимать почему. Добавьте `Tooltip` или текст рядом с недоступным переключателем.
