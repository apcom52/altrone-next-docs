# Data Table

## Выбирайте тип колонки по смыслу данных

Тип колонки — это не только внешний вид. Он определяет форматирование с учётом языка, сортировку и набор правил фильтра: у чисел и дат есть «больше», «меньше» и «между», у строк — «содержит». Если превратить сумму или дату в готовую строку, сортировка начнёт идти по алфавиту, а фильтры — по подстроке.

## Оставляйте на виду одно-два действия

В строке помещается мало места, а каждая иконка-кнопка — ещё одна цель, которую надо найти и не промахнуться. Главное действие держите видимым, остальные уберите в меню через `collapsed`, а необратимые отделите от частых.

## Доступность

- Действия без подписи (`showLabel={false}`) всё равно получают `aria-label` из `label` — всегда задавайте осмысленный `label`.
- Заголовки сортируемых колонок доступны с клавиатуры; не отключайте `sortable` там, где пользователю нужно сравнивать значения.
- Не передавайте смысл только цветом: статус в `custom`-ячейке сопровождайте текстом, как «Active» в метке.
- Для таблицы, которая обновляется снаружи, задавайте `getRowId` — иначе открытое меню действий может «переехать» на другую строку.
