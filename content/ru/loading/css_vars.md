# Loading

CSS-переменные, которые читает `Loading` и которые можно переопределять.

:::spoiler[Как переопределить переменные]
Переменные заданы на корне приложения, поэтому проп `style` у `Loading` — надёжный способ изменить их для одного спиннера: значение в нём сильнее значений по умолчанию.

```tsx
<Loading
  size={40}
  strokeWidth={3}
  style={{
    "--loading-color": "var(--accent-11)",
    "--loading-track-opacity": "0.32",
  } as React.CSSProperties}
/>
```

::playground{src=loading/LoadingCssVarsDemo caption="Акцентный цвет и более заметная дорожка"}

Проп `color` и `style.color` сильнее `--loading-color`: если задан любой из них, переменная игнорируется. У дорожки нет своего цвета — это цвет обводки с прозрачностью `--loading-track-opacity`. Размер и толщина обводки через переменные не настраиваются: для них есть пропы `size` и `strokeWidth`. Переходы цвета и длины дуги следуют глобальным токенам анимации ниже.
:::

## Внутренние переменные

Определены самим компонентом.

::::css-vars
:::css-var[--loading-color]{kind="text" type="Цвет текста" color="var(--text-2)"}
Цвет дуги и дорожки. По умолчанию: `var(--text-2)`
:::

:::css-var[--loading-track-opacity]{kind="opacity" type="Прозрачность"}
Прозрачность дорожки — полного круга за дугой. По умолчанию: `0.16`
:::
::::

## Глобальные переменные

Не определены самим компонентом, но влияют на его вид.

::::css-vars
:::css-var[--text-2]{kind="text" type="Цвет текста" color="var(--text-2)"}
Значение по умолчанию для `--loading-color`.
:::

:::css-var[--motion-duration-base]{kind="duration" type="Длительность"}
Длительность переходов цвета и длины дуги; `0s` при сниженной анимации. По умолчанию: `0.2s`
:::

:::css-var[--motion-easing-standard]{kind="easing" type="Плавность"}
Плавность переходов цвета и длины дуги. По умолчанию: `ease`
:::
::::
