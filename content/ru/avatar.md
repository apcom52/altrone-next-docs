# Avatar

Аватар — это самый быстрый способ узнать пользователя в интерфейсе: фото, иконка или инициалы работают как якорь взгляда в списках, шапках и комментариях. `Avatar` разрешает приоритет в таком порядке: фото (`imageSrc`) → иконка (`icon`) → инициалы. Если фото нет или оно не загрузилось, компонент автоматически откатывается на следующий уровень. Элемент имеет `role="img"` с полным именем в `aria-label`.

## Базовое использование

Инициалы формируются из `firstName` и `lastName`. Если фамилия не передана, используется только первая буква имени.

```tsx
<Avatar firstName="Alex" lastName="Morgan" />
```

::playground{src=AvatarBasicDemo}

## Размеры

`size` управляет диаметром аватара и размером шрифта инициалов.

```tsx
<Avatar firstName="Alex" lastName="Morgan" size="mini" />
<Avatar firstName="Alex" lastName="Morgan" size="s" />
<Avatar firstName="Alex" lastName="Morgan" size="m" />
<Avatar firstName="Alex" lastName="Morgan" size="l" />
<Avatar firstName="Alex" lastName="Morgan" size="xl" />
```

::playground{src=AvatarSizesDemo caption="mini, s, m, l, xl"}

`m` — размер по умолчанию, подходит для большинства списков и таблиц. `xl` хорошо работает в шапке профиля, `mini` — в плотных строках комментариев.

## Фото профиля

Передайте `imageSrc`, чтобы показать фотографию. Если изображение не загрузилось, компонент автоматически покажет инициалы — без дополнительной обработки ошибок со стороны разработчика.

```tsx
<Avatar
  firstName="Nino"
  lastName="Kobakhidze"
  imageSrc="https://example.com/avatar.jpg"
  size="l"
/>
```

::playground{src=AvatarPhotoDemo caption="Слева — фото загрузилось. Справа — битая ссылка, откат на инициалы"}

:::note
Если `imageSrc` меняется на новое значение, состояние ошибки сбрасывается, и компонент пытается загрузить новое изображение заново.
:::

## Иконка вместо инициалов

Передайте `icon`, чтобы показать иконку для сущностей без личного имени — бота, общей команды, неизвестного пользователя. Иконка используется всегда, когда нет фото, и имеет приоритет над инициалами: `firstName`/`lastName` в этом случае можно не передавать.

```tsx
import { Bot } from "lucide-react";

<Avatar icon={<Bot />} aria-label="Бот поддержки" />
```

::playground{src=AvatarIconDemo caption="Иконка вместо инициалов, без имени"}

:::note
Без `firstName` компонент не может построить `aria-label` из имени — передайте его явно, как в примере выше.
:::

## Цвет фона и текста

Без `backgroundColor` фон — категориальный цвет, детерминированно выбранный по имени: один и тот же человек всегда получает один и тот же цвет. Цвет текста считается автоматически по контрасту с фоном; `textColor` его переопределяет.

```tsx
<Avatar firstName="Alice" lastName="Blue" backgroundColor="#6366f1" />
<Avatar
  firstName="Alice"
  lastName="Gold"
  backgroundColor="#1e3a5f"
  textColor="#fbbf24"
/>
```

## Группа аватаров

Стандартного компонента для стека нет — соберите его вручную с помощью отрицательного `marginLeft` и `boxShadow` в качестве обводки. Проп `title` добавляет нативную подсказку браузера.

```tsx
{members.map((member) => (
  <Avatar
    key={member.firstName}
    firstName={member.firstName}
    lastName={member.lastName}
    backgroundColor={member.backgroundColor}
    style={{ marginLeft: -12, boxShadow: "0 0 0 2px var(--background-1)" }}
    title={`${member.firstName} ${member.lastName}`}
  />
))}
```

Чтобы показать, сколько участников скрыто, передайте счётчик как `firstName` — компонент отрендерит его как обычные инициалы.

```tsx
<Avatar firstName="+4" lastName="" style={{ marginLeft: -12 }} />
```

## Свойства

:::prop[firstName]{type="string"}
Имя. Используется для первой буквы инициалов и как часть `aria-label`. Необязателен — можно не передавать для аватара без личного имени (бот, команда), тогда вместо инициалов нужна `icon`.
:::

:::prop[lastName]{type="string"}
Фамилия. Добавляет вторую букву инициалов, если передана.
:::

:::prop[size]{type="'mini' | 's' | 'm' | 'l' | 'xl'" default="'m'"}
Размер аватара.
:::

:::prop[imageSrc]{type="string"}
Ссылка на фотографию. При ошибке загрузки компонент откатывается на `icon` (или инициалы).
:::

:::prop[icon]{type="ReactElement"}
Иконка, которая показывается вместо инициалов, когда нет фото (или оно не загрузилось). Имеет приоритет над инициалами.
:::

:::prop[backgroundColor]{type="string"}
Цвет фона круга. Любое валидное CSS-значение цвета. Без этого пропа — категориальный цвет, детерминированно выбранный по имени.
:::

:::prop[textColor]{type="string"}
Цвет инициалов или иконки. Переопределяет автоматический расчёт контраста.
:::

## Рекомендации

**Всегда передавайте `lastName`, если он есть.** Одна буква вместо двух хуже различает пользователей в списках с похожими именами.

**Не полагайтесь на `imageSrc` без проверки, что фото действительно загружается.** Встроенный фолбэк на инициалы избавляет от лишней логики — не оборачивайте `Avatar` в собственную проверку `onError`.

**Для стека аватаров ограничивайте видимое число участников.** Три-четыре аватара плюс overflow-счётчик читаются лучше, чем десяток перекрывающихся кружков.

**`backgroundColor` нужен редко.** По умолчанию цвет и так закреплён за именем детерминированно — переопределяйте его, только если цвет должен приходить из вашей модели данных (например, по id или роли).

**Для аватара без имени всегда передавайте `aria-label`.** Без `firstName` компонент не может построить осмысленный `aria-label` сам — озвучьте, что это за сущность (бот, команда, гость).
