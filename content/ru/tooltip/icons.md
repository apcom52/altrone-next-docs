# Tooltip

`Tooltip` сам рисует ровно одну иконку — знак `?` на кнопке, которую он создаёт автоматически, если `children` не передан. Она не действует, если передан кастомный триггер через `children` — рисовать её там уже не на чем.

:::spoiler[Как её заменить]
Два способа переопределения, в зависимости от масштаба:

- **Для одного тултипа** — передайте `triggerIcon`:

  ```tsx
  <Tooltip content="A secret key for accessing the API." triggerIcon={<Info size={16} />} />
  ```

- **Для всех иконок-подсказок в приложении** — `triggerIcon` по умолчанию берётся из общей роли `help` из `useIcons()`, той же, что использует собственная иконка-подсказка `Form.Field`. Переопределите её один раз на `Application`, а не на каждом `Tooltip`:

  ```tsx
  <Application icons={{ help: <Info /> }}>
    <YourApp />
  </Application>
  ```

::playground{src=tooltip/TooltipTriggerIconDemo caption="Кастомный triggerIcon на одном тултипе"}

Автоматически создаваемая кнопка — это фиксированный круг 24×24px; выбирайте размер иконки около `16px`, чтобы у неё оставался визуальный запас, как у стандартной `HelpCircle`.
:::
