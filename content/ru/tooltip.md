# Tooltip

Короткая всплывающая подсказка, привязанная к элементу. Появляется через 500 мс после наведения или немедленно при фокусе — и исчезает сразу при уходе курсора. `Tooltip` сообщает контекст, не захламляя интерфейс постоянно видимым текстом.

## Базовый пример

```tsx
<Tooltip content="Скопировать в буфер обмена">
  <Button label="Копировать" icon={<Copy />} showLabel={false} />
</Tooltip>
```

## Заголовок и горячая клавиша

`title` добавляет жирный заголовок над текстом. `kbd` — бейдж горячей клавиши. Используйте вместе для кнопок панели инструментов.

```tsx
<Tooltip title="Сохранить документ" content="Сохраняет все несохранённые изменения." kbd="⌘S">
  <Button label="Сохранить" icon={<Save />} showLabel={false} />
</Tooltip>
```

::playground{src=TooltipTitleKbdDemo caption="title и kbd хорошо работают для кнопок без текста"}

## Иконка-вопрос (без children)

Если `children` не передан, `Tooltip` сам рендерит кнопку с иконкой `?`. Используйте рядом с полями форм и техническими терминами.

```tsx
<Flex gap="xs" align="center">
  <span>API-ключ</span>
  <Tooltip content="Секретный ключ для доступа к API. Никогда не публикуйте его." />
</Flex>
```

## Позиционирование

По умолчанию тултип появляется сверху. `placement` принимает любую строку позиционирования Floating UI: `top`, `bottom`, `left`, `right` и их варианты с суффиксами `-start` / `-end`. При нехватке места тултип автоматически переворачивается.

```tsx
<Tooltip content="Сверху"  placement="top">…</Tooltip>
<Tooltip content="Снизу"   placement="bottom">…</Tooltip>
<Tooltip content="Слева"   placement="left">…</Tooltip>
<Tooltip content="Справа"  placement="right">…</Tooltip>
```

::playground{src=TooltipPlacementsDemo}

## Тултип на отключённом элементе

Отключённый `<button>` не генерирует события мыши — тултип не появится. Оберните в `<span>`, чтобы перехватить события.

```tsx
<Tooltip content="Сначала выберите хотя бы один элемент">
  <span>
    <Button label="Удалить" disabled />
  </span>
</Tooltip>
```

## Произвольный контент

`content` принимает любой `ReactNode`. Используйте для структурированных подсказок с несколькими строками.

```tsx
<Tooltip
  content={
    <Flex orientation="vertical" gap="xs">
      <strong>Лимиты тарифа</strong>
      <span>5 проектов · 3 участника · 10 ГБ</span>
    </Flex>
  }
  maxWidth={240}
>
  <span>Текущий тариф</span>
</Tooltip>
```

## Свойства

:::prop[content*]{type="string | ReactElement"}
Текст или элемент внутри тултипа.
:::

:::prop[children]{type="ReactNode"}
Элемент-триггер. Если не передан — рендерится кнопка с иконкой `?`.
:::

:::prop[title]{type="string"}
Жирный заголовок над `content`.
:::

:::prop[kbd]{type="string"}
Бейдж горячей клавиши, отображается после `content`.
:::

:::prop[placement]{type="Placement" default="'top'"}
Позиция тултипа относительно триггера. Автоматически переворачивается при нехватке места.
:::

:::prop[maxWidth]{type="number | string"}
Максимальная ширина панели тултипа.
:::

## Рекомендации

**Тултип — для пояснений, не для обязательной информации.** Если без тултипа интерфейс непонятен — это проблема самого интерфейса, а не недостаток объяснений. Тултип помогает опытному пользователю, но не должен быть единственным способом понять действие.

**Используйте `kbd` для горячих клавиш.** Показывать сочетание клавиш прямо в тултипе — лучшее место для обучения: пользователь видит подсказку именно тогда, когда думает о действии.

**Не прячьте критический текст в тултипах.** Пользователи мобильных устройств и люди с ограниченными возможностями могут не получить доступа к содержимому. Обязательные объяснения должны быть видны постоянно.
