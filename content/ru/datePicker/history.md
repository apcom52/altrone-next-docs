# Date Picker

:::release[Altrone 4 Decent Dragon]{icon="/logos/altrone-4.png" logo="DatePicker" name="DatePicker" open="true"}
**4.0**

- Новый дизайн.
- Новый колбэк для `RangePicker`.
- Контрол можно заменить через `asChild` и `useDatePickerTrigger()`.
- `onChange` получает объект события.
- Значение в поле меняется вместе с языком приложения (`Application.language`).
- Кнопки «Сегодня», «Этот месяц» и «Этот год» блокируются вне `minDate`/`maxDate`.
- Курсор над полем — «рука».
- Читает `disabled` и `size` из `Form`.
:::
