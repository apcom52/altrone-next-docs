# Spoiler

Сворачиваемая секция с анимацией высоты. Заголовок всегда виден — клик по нему раскрывает или сворачивает содержимое. Состояние управляется внутри компонента, колбэк `onToggle` позволяет реагировать на переключения снаружи.

## Базовый пример

```tsx
<Spoiler title="Что такое Altrone UI?">
  <p>Altrone UI — библиотека React-компонентов с современной дизайн-системой.</p>
</Spoiler>
```

::playground{src=SpoilerBasicDemo caption="Нажмите на заголовок, чтобы раскрыть содержимое"}

## Раскрыт по умолчанию

`openedByDefault` задаёт начальное состояние. После первого рендера компонент живёт самостоятельно — проп не синхронизируется с последующими изменениями состояния.

```tsx
<Spoiler title="Системные требования" openedByDefault>
  <Text block>React 18+, TypeScript 4.9+</Text>
</Spoiler>
```

::playground{src=SpoilerDefaultOpenDemo caption="Первый блок раскрыт по умолчанию, второй — свёрнут"}

## Список FAQ

Несколько `Spoiler` подряд образуют аккордеон без дополнительной обёртки. Они не связаны друг с другом — можно раскрыть сколько угодно одновременно.

```tsx
{faqs.map((faq) => (
  <Spoiler key={faq.id} title={faq.question}>
    <Text block>{faq.answer}</Text>
  </Spoiler>
))}
```

## Реакция на переключение

`onToggle` получает новое состояние (`true` — открыт) после каждого клика. Используйте для аналитики, ленивой загрузки содержимого или синхронизации с URL.

```tsx
<Spoiler
  title="Дополнительные настройки"
  onToggle={(opened) => {
    if (opened) loadAdvancedSettings();
  }}
>
  <AdvancedSettingsForm />
</Spoiler>
```

## Внутри формы

`Spoiler` хорошо работает как контейнер для опциональных полей формы. Пользователь видит основные поля сразу, а дополнительные раскрывает по мере необходимости.

```tsx
<Spoiler title="Дополнительные поля">
  <Form.Field name="notes" label="Примечания">
    <Textarea value={notes} onChange={(e) => setNotes(e.target.value)} />
  </Form.Field>
  <Form.Field name="tags" label="Теги">
    <TextInput value={tags} onChange={setTags} />
  </Form.Field>
</Spoiler>
```

## Свойства

:::prop[title*]{type="string"}
Всегда видимый заголовок. Клик по нему переключает состояние.
:::

:::prop[children]{type="ReactNode"}
Содержимое, скрытое в свёрнутом состоянии.
:::

:::prop[openedByDefault]{type="boolean" default="false"}
Начальное состояние. После монтирования не синхронизируется с изменениями пропа.
:::

:::prop[onToggle]{type="(opened: boolean, event: MouseEvent) => void"}
Вызывается после каждого переключения. `opened` — новое состояние.
:::

## Рекомендации

**`Spoiler` не является контролируемым компонентом.** Состояние открыт/закрыт живёт внутри. Если вам нужно управлять им снаружи — реализуйте аналог вручную через `details`/`summary` или кастомный компонент с `useState`.

**Не прячьте важное.** `Spoiler` подходит для дополнительного контекста, FAQ, вторичных настроек. Если содержимое критично для выполнения задачи — оно должно быть видно сразу.

**Анимация работает через `motion/react`.** Высота плавно переходит от `0` до `auto`. Не применяйте собственные переходы к содержимому — они будут конфликтовать с внутренней анимацией.

**Для одного активного блока реализуйте аккордеон явно.** `Spoiler` сам по себе не ограничивает одновременно открытые секции. Если нужно, чтобы раскрытие одного закрывало другие — управляйте состоянием снаружи через `onToggle`.
