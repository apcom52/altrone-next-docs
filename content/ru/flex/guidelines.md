# Flex

## Берите Flex и токен, а не свою раскладку с пикселями

`gap="m"` привязан к дизайн-системе: расстояние останется согласованным со всем интерфейсом и изменится вместе с ним. Самодельный `div` с `display: flex` и значением в пикселях выпадает из ритма и не подчиняется шкале.

::::good-bad
:::good
```tsx
<Flex gap="m">
  <Button label="Cancel" />
  <Button label="Save" />
</Flex>
```
:::

:::bad
```tsx
<div style={{ display: "flex", gap: 12 }}>
  <Button label="Cancel" />
  <Button label="Save" />
</div>
```
:::
::::

## Расстояние между элементами — это gap, а не внешние отступы

Внутри `Flex` внешние отступы прямых потомков обнуляются, поэтому `margin` у ребёнка ничего не изменит. Не пытайтесь подгонять расстояние полями отдельных элементов — задайте его один раз на контейнере.

::::good-bad
:::good
```tsx
<Flex gap="l">
  <Button label="Back" />
  <Button label="Next" />
</Flex>
```
:::

:::bad
```tsx
<Flex>
  <Button label="Back" style={{ marginRight: 16 }} />
  <Button label="Next" />
</Flex>
```
:::
::::

## Разносите по краям две группы, не три

`justify="between"` читается чисто, когда элементов два: заголовок и действие. Три элемента разъезжаются по всей ширине и перестают выглядеть связанными — сгруппируйте их в два блока или возьмите `Grid`.

## Flex — для одного измерения, Grid — для двух

`Flex` выравнивает элементы вдоль одной оси. Если карточки должны встать в ровные столбцы и строки, `Flex` с `wrap` даст рваную сетку: ширина каждой карточки зависит от её содержимого, и столбцы не совпадают между строками. Для такой раскладки используйте [Grid](/ru/components/layout/grid).

## Используйте настоящие элементы для списков и навигации

Контейнер, который по смыслу список или навигация, должен быть `ul`, `nav` или `section`, а не набором `div`. Через `asChild` `Flex` сохраняет разметку, а скринридеры видят структуру.

::::good-bad
:::good
```tsx
<Flex asChild orientation="vertical" gap="s">
  <ul>
    <li>Profile</li>
    <li>Billing</li>
  </ul>
</Flex>
```
:::

:::bad
```tsx
<Flex orientation="vertical" gap="s">
  <div>Profile</div>
  <div>Billing</div>
</Flex>
```
:::
::::

## Не вкладывайте глубже, чем нужно

Три уровня вложенности — обычное дело. Если внутри `Flex` появляется четвёртый, вынесите вложенный фрагмент в отдельный компонент: раскладку станет легче читать, а повторяющийся кусок можно будет переиспользовать.

## Доступность

- `Flex` меняет только внешний вид: порядок элементов в DOM совпадает с порядком чтения. Не полагайтесь на раскладку, чтобы поменять смысловой порядок, — меняйте порядок в разметке.
- Для списков, навигации и секций используйте семантические элементы через `asChild`, а не `div`.
- Пользуйтесь `wrap` вместо горизонтальной прокрутки: при увеличении масштаба и на узких экранах содержимое перестроится, а не выйдет за край.

Общие правила библиотеки — в статье [Доступность](/ru/foundations/accessibility).
