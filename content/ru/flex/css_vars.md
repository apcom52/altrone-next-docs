# Flex

CSS-переменные, которые читает `Flex` и которые можно переопределить. Собственных переменных у `Flex` нет: расстояние `gap` берётся из глобальных токенов шкалы отступов.

:::spoiler[Как переопределять переменные]
Проп `gap` выбирает токен из шкалы, а `Flex` подставляет его в `gap: var(--…)` на самом элементе. Поэтому переопределить расстояние у одного `Flex` можно через проп `style`: инлайновое значение токена действует сразу. Переопределяйте тот токен, который выбран пропом `gap` (для `gap="m"` — `--gap`).

```tsx
<Flex gap="m" style={{ "--gap": "24px" } as React.CSSProperties}>
  <Box size={20} />
  <Box size={20} />
  <Box size={20} />
</Flex>
```

::playground{src=flex/FlexCssVarsDemo caption="Верхний ряд — gap=m по умолчанию, нижний — тот же токен, переопределённый на 24px"}

Что нужно учитывать:

- **Токен наследуется потомками.** Компоненты внутри, читающие тот же токен, изменятся вместе с контейнером: например, `Button` берёт `--gap` для промежутка между иконкой и подписью.
- **Токен на предке действует на все вложенные `Flex` и `Grid`.** Переопределяйте его на самом контейнере, если менять нужно только его.
- **`gap` в `style` не сработает.** Значение свойства `gap` всегда берётся из пропа `gap`, поэтому меняйте либо проп, либо токен.
:::

## Глобальные переменные

Не определены самим `Flex`: это глобальные дизайн-токены шкалы отступов. Изменение токена меняет расстояние сразу везде, где выбрано соответствующее значение `gap`.

::::css-vars
:::css-var[--narrow-gap]{kind="gap" type="Размер отступа"}
Расстояние для `gap="xxs"`. По умолчанию: `2px`
:::

:::css-var[--xs-gap]{kind="gap" type="Размер отступа"}
Расстояние для `gap="xs"`. По умолчанию: `4px`
:::

:::css-var[--s-gap]{kind="gap" type="Размер отступа"}
Расстояние для `gap="s"`. По умолчанию: `6px`
:::

:::css-var[--gap]{kind="gap" type="Размер отступа"}
Расстояние для `gap="m"`. По умолчанию: `8px`
:::

:::css-var[--l-gap]{kind="gap" type="Размер отступа"}
Расстояние для `gap="l"`. По умолчанию: `12px`
:::

:::css-var[--xl-gap]{kind="gap" type="Размер отступа"}
Расстояние для `gap="xl"`. По умолчанию: `24px`
:::

:::css-var[--xxl-gap]{kind="gap" type="Размер отступа"}
Расстояние для `gap="xxl"`. По умолчанию: `36px`
:::
::::
