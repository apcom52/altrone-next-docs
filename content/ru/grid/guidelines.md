# Grid

## Grid — для двух измерений, Flex — для одного

Если нужно выровнять элементы вдоль одной оси — в ряд или в колонку, — берите [Flex](/ru/components/layout/flex). `Grid` нужен, когда столбцы должны совпадать между рядами: карточки, макет страницы, форма из нескольких полей в строке. Сравнение на живом примере — в [гайдлайнах Flex](/ru/components/layout/flex/guidelines).

## Складывайте размеры колонок в 12

Ряд, у которого сумма `size` равна 12, заполняет контейнер целиком. Если сумма меньше, справа остаётся пустое место, которое выглядит как ошибка, а не как решение. Нужен пустой край — задайте его явно через `offset`.

## Кнопкам — auto, полям — явный размер

Ширина кнопки определяется подписью, а не сеткой. Колонка `auto` подстраивается под содержимое, а колонка с фиксированным `size` может оказаться уже подписи — кнопка сожмётся или выйдет за колонку. Поле ввода и блоки контента, наоборот, получают явный `size`, чтобы забрать остаток ряда.

## Задавайте rowGap вместе с gap

`gap` управляет только расстоянием между колонками. Если карточки переносятся на новый ряд, а `rowGap` не задан, ряды слипаются. Обычно `gap` и `rowGap` совпадают — разные значения нужны, только когда так задумано.

## Меняйте размеры колонок на узких экранах

Пропорции колонок не меняются вместе с шириной экрана: `size={4}` всегда занимает треть контейнера, и на телефоне такие колонки станут слишком узкими. `Grid` сам не реагирует на ширину окна и `size` не меняется неявно — выберите набор размеров под экран самостоятельно, например по `useBreakpoint()`.

```tsx
const { isMd } = useBreakpoint();

<Grid gap="m" rowGap="m">
  {cards.map((card) => (
    <Grid.Column key={card.id} size={isMd ? 4 : 12}>
      <Card {...card} />
    </Grid.Column>
  ))}
</Grid>
```

Значения `useBreakpoint()` известны только после первого рендера в браузере, поэтому до этого момента `Grid` использует набор для узкого экрана.

## Не используйте Grid для мелких выравниваний

Пара элементов, которые нужно выровнять по краям или по центру, — задача `Flex`. Сетка из двенадцати колонок ради двух кнопок усложняет разметку и мешает читать код.

## Доступность

- `Grid` меняет только внешний вид: порядок колонок в DOM совпадает с порядком чтения. `offset` сдвигает колонку визуально и не меняет этот порядок.
- Для списка карточек используйте `ul` и `li` через `asChild`, а не набор `div`.
- Не полагайтесь на положение колонки в сетке, чтобы передать смысл: он должен быть ясен и из последовательности элементов в разметке.

Общие правила библиотеки — в статье [Доступность](/ru/foundations/accessibility).
