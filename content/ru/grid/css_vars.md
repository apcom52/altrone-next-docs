# Grid

CSS-переменные, которые читает `Grid` и которые можно переопределить. Собственных переопределяемых переменных у `Grid` нет: расстояния `gap` и `rowGap` берутся из глобальных токенов шкалы отступов.

:::spoiler[Как переопределять переменные]
Пропы `gap` и `rowGap` выбирают токены из шкалы, а `Grid` подставляет их в расстояния между колонками и рядами на самом элементе. Поэтому переопределить расстояние у одной сетки можно через проп `style`: инлайновое значение токена действует сразу. Переопределяйте тот токен, который выбран пропом (для `gap="m"` — `--gap`).

```tsx
<Grid gap="m" rowGap="s" style={{ "--gap": "24px" } as React.CSSProperties}>
  <Grid.Column size={6}>A</Grid.Column>
  <Grid.Column size={6}>B</Grid.Column>
</Grid>
```

::playground{src=grid/GridCssVarsDemo caption="Расстояние между колонками — токен --gap, переопределённый на 24px"}

Что нужно учитывать:

- **Токен наследуется потомками.** Компоненты внутри колонок, читающие тот же токен, изменятся вместе с сеткой: например, `Button` берёт `--gap` для промежутка между иконкой и подписью.
- **Токен на предке действует на все вложенные `Flex` и `Grid`.** Переопределяйте его на самой сетке, если менять нужно только её.

Что переопределить нельзя:

- **`--grid-column-spacing` и `--grid-row-spacing`.** `Grid` задаёт их инлайн-стилем из пропов `gap` и `rowGap`, поэтому меняйте проп или токен.
- **`--grid-column-size` и `--grid-column-offset`.** `Grid.Column` вычисляет их из `size` и `offset` и задаёт инлайн-стилем.
:::

## Глобальные переменные

Не определены самим `Grid`: это глобальные дизайн-токены шкалы отступов. Изменение токена меняет расстояние сразу везде, где выбрано соответствующее значение `gap` или `rowGap`.

::::css-vars
:::css-var[--narrow-gap]{kind="gap" type="Размер отступа"}
Расстояние для значения `xxs`. По умолчанию: `2px`
:::

:::css-var[--xs-gap]{kind="gap" type="Размер отступа"}
Расстояние для значения `xs`. По умолчанию: `4px`
:::

:::css-var[--s-gap]{kind="gap" type="Размер отступа"}
Расстояние для значения `s`. По умолчанию: `6px`
:::

:::css-var[--gap]{kind="gap" type="Размер отступа"}
Расстояние для значения `m`. По умолчанию: `8px`
:::

:::css-var[--l-gap]{kind="gap" type="Размер отступа"}
Расстояние для значения `l`. По умолчанию: `12px`
:::

:::css-var[--xl-gap]{kind="gap" type="Размер отступа"}
Расстояние для значения `xl`. По умолчанию: `24px`
:::

:::css-var[--xxl-gap]{kind="gap" type="Размер отступа"}
Расстояние для значения `xxl`. По умолчанию: `36px`
:::
::::
