# Text

## Выбирайте размер по роли, а не по важности

Крупный размер не делает текст важным — важный текст сообщает что-то существенное. Выбирайте размер по роли в иерархии: подпись, основной текст, заголовок. Двух-трёх размеров и двух-трёх начертаний на экран достаточно; каждое отклонение от базового стиля должно что-то значить.

## Используйте семантические цвета по смыслу

`danger` — для ошибок, `success` — для подтверждений, `warning` — для того, что требует осторожности. Люди запоминают значение цветов, поэтому красное слово там, где нет проблемы, учит игнорировать настоящие. Для просто второстепенного текста есть `muted`.

Никогда не полагайтесь только на цвет: сочетайте `danger` и `success` со словами, которые говорят то же самое, как в примере выше.

## Для параграфа используйте block

Строчный `<span>` по умолчанию — намеренно: `Text` может жить внутри предложения. Когда текст — самостоятельный параграф, переключайтесь на `block`: он получит свою строку, межстрочный интервал для чтения и правильный элемент.

## Обрезайте только то, что нельзя предсказать

`truncate` — для текста, длину которого вы не контролируете: имена файлов, пользовательский ввод, данные из API. Если подпись обрезается всегда — исправьте верстку, а не прячьте проблему за многоточием. И оставьте полный текст доступным: `title`, подсказка или экран с деталями.

## Делайте ссылки настоящими ссылками

Навигация — это `<a>`: используйте `href`. `Text` с `onClick` выглядит как ссылка, но не получает фокус, не открывается в новой вкладке и не озвучивается как ссылка. Для действия, которое лишь выглядит как текст, используйте `asChild` с настоящей `<button>`.

## Не украшайте без смысла

Комбинируйте декорации осторожно: чем больше стилей в одной строке, тем труднее понять, что важно. `code` — для кода, `kbd` — для клавиш, `highlighted` — как маркер, и не складывайте их друг на друга.

## Доступность

- `Text` никогда не рендерит заголовок. Используйте `asChild` с `<h1>`–`<h6>`, чтобы программы чтения с экрана получили структуру документа.
- `code`, `kbd` и `deleted` — визуальные стили на `<span>`. Если смысл важен для вспомогательных технологий, отрисуйте настоящий элемент: `<Text asChild code><code>…</code></Text>`, `<kbd>`, `<del>`.
- Размеры `1` и `2` (8px и 10px) — только для декоративного или дополнительного текста. Содержимое держите на `3` (12px) и крупнее.
- Контраст соответствует WCAG AA — 4.5:1 для текста. Семантические цвета подобраны под него в обеих темах; любой цвет, который вы задаёте сами через `--text-color`, проверяйте.
- Ссылка отличается от окружающего текста цветом и начертанием. В длинном параграфе добавьте `underline`, чтобы она не зависела только от цвета.
- Обрезанный текст скрывает содержимое: оставьте полный текст доступным через `title`, подсказку или другой экран.

Общие правила библиотеки — в статье [Доступность](/ru/foundations/accessibility).
