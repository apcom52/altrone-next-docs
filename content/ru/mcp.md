# MCP

`@altrone/mcp` — небольшой отдельный пакет, который напрямую отдаёт собственную документацию Altrone MCP-клиентам — Claude Desktop, Claude Code и всему остальному, что говорит на Model Context Protocol. Вместо того чтобы ИИ-агент угадывал пропы компонента по обучающим данным (которые могут быть устаревшими или просто неверными для этой библиотеки), он может вызвать инструмент и прочитать реальное описание.

## Что он предоставляет

Три инструмента, каждый опирается на обычный Markdown-файл, а не на базу данных или сгенерированную схему:

| Инструмент | Что делает |
| --- | --- |
| `list_components` | Перечисляет все задокументированные компоненты |
| `get_component_docs` | Возвращает полную документацию одного компонента по имени |
| `get_guidelines` | Возвращает обязательные правила использования — какие компоненты применять вместо сырого HTML, конвенцию импорта, паттерны лэйаута/форм/обратной связи |

Собственное описание инструмента `list_components` написано так, чтобы подталкивать вызывающего агента сначала обратиться к `get_guidelines` — это осознанная инструкция, зашитая прямо в сам инструмент, а не просто текст, написанный здесь прозой, поскольку агент читает описания инструментов раньше, чем любую статью.

## Настройка

```json
{
  "mcpServers": {
    "altrone": {
      "command": "node",
      "args": ["/absolute/path/to/altrone-mcp/dist/index.js"]
    }
  }
}
```

Для локальной разработки можно пропустить шаг сборки и запускать исходники напрямую:

```json
{
  "mcpServers": {
    "altrone": {
      "command": "npx",
      "args": ["tsx", "/absolute/path/to/altrone-mcp/src/index.ts"]
    }
  }
}
```

## Как это остаётся синхронизированным с библиотекой компонентов

У каждого компонента ровно один Markdown-файл в `docs/`, названный по имени компонента (`Button.md`, `TextInput.md`, …) — сервер при запуске перечисляет то, что реально лежит в этой папке, так что добавление, переименование или удаление файла документации компонента — это и есть всё обновление; изменений кода на стороне сервера не требуется.
