# Application

CSS-переменные `Application`, которые можно переопределить. Они управляют фоном страницы, цветом текста и шрифтом всего приложения.

:::spoiler[Как переопределять переменные]
Самый надёжный способ — проп `style`: значение, заданное прямо на элементе, перебивает значение по умолчанию в обеих темах. Правило в вашей таблице стилей тоже подойдёт, но его селектор должен быть специфичнее `[data-altrone-root='true']`.

```tsx
<Application
  style={{ '--app-font-family': "'Georgia', serif" } as React.CSSProperties}
>
  <App />
</Application>
```

Фиксированный цвет заменяет значение по умолчанию, которое подстраивается под тему, поэтому в светлой и тёмной теме он выглядит одинаково. Чтобы обе темы продолжали работать, используйте токен, например `var(--gray-2)`, а не обычный цвет.

`Application` копирует фон на `<body>` и `<html>` при запуске и каждый раз, когда меняется тема. За самой переменной он не следит: если вы измените её позже, пока приложение работает, копия обновится только при следующей смене темы. Прозрачный фон (`transparent`) не копируется никогда.

Что переопределить нельзя:

- **Цвета, скопированные на `<html>` и `<body>`.** Они вычисляются из `--app-background`, поэтому меняйте переменную, а не сами стили.
- **Токены, которые на корне выставляют другие части библиотеки** — акцент, статусные и серые цвета, отступы, радиусы. Они относятся к своим темам; см. [Цвет](/ru/foundations/color).
:::

## Внутренние переменные

Определяются самим `Application`.

::::css-vars
:::css-var[--app-background]{kind="fill" type="Цвет заливки" color="var(--background-1)"}
Фон приложения и страницы, копируется и на `<body>`. По умолчанию: `var(--background-1)`
:::

:::css-var[--app-text-color]{kind="text" type="Цвет текста" color="var(--text-2)"}
Цвет текста приложения по умолчанию. По умолчанию: `var(--text-2)`
:::

:::css-var[--app-font-family]{kind="font" type="Шрифт"}
Шрифт всего текста в приложении. По умолчанию: `var(--font-family-base)`
:::
::::

## Глобальные переменные

`Application` их не определяет: это общие токены, из которых складываются его значения по умолчанию, и базовые размеры текста, которые он использует. Изменение токена перекрашивает всю библиотеку сразу.

::::css-vars
:::css-var[--background-1]{kind="fill" type="Цвет заливки" color="var(--gray-1)"}
Откуда берётся фон приложения по умолчанию. По умолчанию: `var(--gray-1)`
:::

:::css-var[--text-2]{kind="text" type="Цвет текста" color="var(--gray-12)"}
Откуда берётся цвет текста по умолчанию. По умолчанию: `var(--gray-12)`
:::

:::css-var[--font-family-base]{kind="font" type="Шрифт"}
Откуда берётся шрифт по умолчанию: Inter Variable, а запасными служат системные шрифты. По умолчанию: `'Inter Variable'`
:::

:::css-var[--text-size-4]{kind="font" type="Размер шрифта"}
Базовый размер текста приложения. По умолчанию: `14px`
:::

:::css-var[--line-height-4]{kind="font" type="Высота строки"}
Базовая высота строки приложения. По умолчанию: `20px`
:::
::::
