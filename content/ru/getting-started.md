# Начало работы

Altrone — библиотека React-компонентов для интерфейсов приложений: дашбордов, админок, внутренних инструментов и других приложений, где люди работают с данными. В ней около пятидесяти компонентов — от каркаса страницы и навигации до форм, таблиц и диалогов, — и у всех один внешний вид, один набор дизайн-токенов и одни правила.

::playground{src=gettingStarted/GettingStartedDemo caption="Компоненты Altrone сразу работают вместе: поле, кнопка и тост"}

:::warning Altrone 4 в бете
Эта документация описывает Altrone 4. Он публикуется с тегом `beta`, поэтому API ещё может меняться от релиза к релизу. Тег `latest` в npm пока указывает на Altrone 3. Что изменилось в каждой бете, написано в [релизах](/ru/project/release-notes).
:::

## Что внутри

Компоненты сгруппированы по назначению:

- [Макет](/ru/components/layout) — корень приложения, каркас страницы и примитивы для раскладки: `Application`, `Screen`, `Flex`, `Grid`, `Box`, `Toolbar`, `Splitter`
- [Элементы управления](/ru/components/controls) — всё, с чем пользователь взаимодействует или во что вводит данные: `Button`, `Form`, текстовые и числовые поля, `Select`, `DatePicker`, `FilePicker`, чекбоксы и переключатели
- [Оверлеи](/ru/components/overlays) — то, что показывается поверх страницы: `Modal`, `Drawer`, `Popover`, `Dropdown`, `Tooltip` и диалоги
- [Контент](/ru/components/content) — то, что читают: `Text`, `Image`, `Avatar`, `Tags`, `Calendar`, `DataTable`
- [Обратная связь](/ru/components/feedback) — что приложение делает прямо сейчас: тосты и уведомления, `Message`, `Progress`, `Loading`, `Skeleton`, `Result`
- [Навигация](/ru/components/navigation) — переходы между разделами: `Tabs`, `NavigationList`, `SideNavigation`, `BottomNavigation`, `Breadcrumbs`, `Pagination`

## Как устроено приложение на Altrone

На самом верху стоит `Application`. Своей разметки он не рисует — он передаёт всем компонентам ниже тему, акцентный цвет, язык интерфейса, общие иконки, диалоги и тосты. Внутри каждая страница — это `Screen`: каркас с шапкой, боковой панелью, основным содержимым и другими областями, который сам перестраивается на маленьких экранах.

```tsx
import { Application, Screen, Toolbar, Button } from 'altrone-ui';

export default function App() {
  return (
    <Application applicationName="Acme">
      <Screen title="Projects">
        <Screen.Header>
          <Toolbar>
            <Toolbar.Title label="Projects" />
          </Toolbar>
        </Screen.Header>
        <Screen.Content>
          <Button label="New project" variant="submit" />
        </Screen.Content>
      </Screen>
    </Application>
  );
}
```

Через всю библиотеку проходят несколько идей:

- **Светлая и тёмная темы.** По умолчанию `Application` следует системной теме; каждый цвет — CSS-переменная со значением для каждой темы.
- **Один акцентный цвет.** Выберите один из десяти акцентов пропом `accent` — и все компоненты подстроятся под него. Статусные цвета — ошибка, успех, предупреждение — от акцента не зависят.
- **Размеры.** Элементы управления принимают проп `size` от `mini` до `xl`, и он согласованно меняет отступы, текст, иконки и скругления.
- **Восемь языков.** Встроенные тексты — подписи кнопок, пустые состояния, подписи для скринридеров — есть на английском, русском, французском, немецком, испанском, китайском, португальском и турецком; любой из них можно заменить.
- **Свои элементы.** Компоненты, которые рисуют ссылку или кнопку, принимают `asChild` — на их место можно поставить `<Link>` вашего роутера и сохранить стили.
- **Вызов откуда угодно.** Тосты, уведомления и диалоги — обычные функции (`showToast`, `showConfirm`), их можно вызвать из обработчика клика, стора или любого модуля.
- **Доступность.** Компоненты используют нативные элементы, где они есть, поддерживают клавиатуру и учитывают настройку уменьшения движения.

## Altrone и ИИ-агенты

Если вы пишете код с Claude, Cursor или другим ИИ-ассистентом, подключите [MCP-сервер Altrone](/ru/foundations/mcp). Он отдаёт агенту актуальную документацию каждого компонента, и тому не приходится угадывать пропсы по устаревшим данным из обучения.
