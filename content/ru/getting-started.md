# Начало работы

Altrone UI — библиотека React-компонентов для создания современных, доступных веб-приложений. Включает 50+ готовых компонентов, встроенную систему тем и полную поддержку TypeScript.

## Возможности

- **50+ компонентов** — кнопки, формы, модальные окна, навигация, отображение данных и другое
- **Темизация** — настройка цветов, шрифтов и отступов через CSS-переменные
- **Доступность** — соответствует WAI-ARIA, навигация с клавиатуры из коробки
- **TypeScript** — полностью типизированное API с поддержкой автодополнения

## Требования

Для работы Altrone UI необходимы следующие зависимости:

- React 18 или выше
- TypeScript 4.9+

## Быстрый пример

```tsx
import { Button } from 'altrone-ui'
import 'altrone-ui/dist/style.css'

export default function App() {
  return <Button label="Нажми меня" onClick={() => alert('Привет!')} />
}
```

:::tip
Оберните приложение компонентом `AltroneApplication`, чтобы включить тематизацию и единообразный стиль для всех компонентов.
:::
