# Radio

## Для коротких списков — Radio, для длинных — Select

Когда вариантов от двух до пяти, показывайте их все: пользователь сравнивает варианты глазами и выбирает одним кликом. Выпадающий список прячет варианты за дополнительным нажатием, что оправдано только когда их много.

## Выбирайте вариант по умолчанию

Из радиокнопок нельзя снять выбор, поэтому группа без выбранного варианта оставляет пользователя перед неочевидным вопросом: нужно ли отвечать вообще. Если у настройки есть разумное значение по умолчанию, выберите его заранее. Группу без выбора оставляйте только там, где ответ обязателен и вам важно, чтобы человек сделал его осознанно.

## Объясняйте, чем варианты отличаются

Подпись должна позволять выбрать, не открывая справку. «Вариант A» и «Вариант B» не говорят ничего; название с коротким пояснением говорит о последствиях выбора.

## Не заменяйте Radio чекбоксами и наоборот

Радиокнопки означают «один из», а чекбоксы — «любое количество». Если пользователь может выбрать несколько вариантов или ни одного, используйте `Checkbox`. Для одиночного «да / нет» тоже подходит `Checkbox` или `Switch`, а не группа из двух радиокнопок.

## Доступность

- Группа должна иметь общее имя. Добавьте на `Radio` атрибуты `role="radiogroup"` и `aria-labelledby`, указывающий на заголовок вопроса, — они передаются корневому `<div>`.
- У каждого варианта должна быть подпись; если её нет, задайте `aria-label` или `aria-labelledby`.
- Варианты — нативные радиокнопки: `Tab` входит в группу, стрелки перемещают выбор, `Space` выбирает вариант.
- Выбранное состояние передаётся точкой внутри кружка, а не одним цветом.
- Кликабельная строка не ниже 24px на любом размере.
