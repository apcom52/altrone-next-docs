# Image

`Image` — это подпись-фигура для контента статей: фото, иллюстрация или диаграмма с опциональной подписью. Сама картинка может быть как ссылкой (`src`), так и произвольным элементом в `children` — компонентом `next/image`, инлайновым `svg`, `picture` с несколькими источниками — чем угодно. Пока картинка грузится, кадр закрыт плейсхолдером-скелетоном; если `src` не загрузился, вместо битой иконки браузера показывается нейтральная заглушка. Кадр всегда выровнен по центру компонента, даже если `width` уже своего контейнера. В режиме `src` сама картинка (не кадр) получает тонкую внутреннюю обводку (`--border-a1`) и лёгкую тень (`--elevation-raised-shadow`, та же роль, что у `Tabs.Item`/дня в `DatePicker`) — и только когда картинка реально есть: у скелетона загрузки и у заглушки битого изображения ни обводки, ни тени нет. При `fit="contain"`/`"scale-down"`/`"none"` бокс картинки сжимается по контенту, поэтому обводка и тень облегают именно видимое изображение, а не пустое пространство леттербокса вокруг него. В режиме `children` нет ни обводки, ни тени, а картинка всегда занимает весь кадр (100%×100%) независимо от `fit` — произвольная картинка оформляется потребителем самостоятельно, да и у контента без intrinsic-размера (например, голого `<svg>`) всё равно нет ничего надёжного, чтобы под него сжиматься.

## Базовое использование

```tsx
<Image
  src="https://example.com/fjord.jpg"
  alt="Фьорд на закате"
  caption="Фьорд на закате"
  width="100%"
  height={240}
/>
```

## Object-fit

`fit` управляет тем, как картинка вписывается в кадр — как обычный CSS `object-fit`.

```tsx
<Image src={photo} alt="Портрет" fit="contain" width={220} height={140} />
```

:::note
`fit`/`objectPosition` применяются к тому, что реально оказалось в DOM — `<img>`, `<svg>`, `<video>` — независимо от того, кто это отрендерил: `Image` сам или произвольный `children`.
:::

## Произвольная картинка через `children`

Если рендерингом картинки должен управлять кто-то другой — `next/image`, кастомный `svg`, график — передайте его как `children` вместо `src`. `Image` возьмёт на себя только рамку, `fit` и подпись.

:::note
Обёртка в режиме `children` всегда занимает 100%×100% кадра (в отличие от `contain`/`scale-down`/`none` в режиме `src`, где картинка сжимается по контенту) и не получает ни обводки, ни тени — задайте дочернему элементу собственный размер (например, `width="100%" height="100%"` у `<svg>`), если он должен заполнить этот бокс, и оформление, если оно нужно.
:::

```tsx
<Image fit="cover" width="100%" height={200} caption="Северное сияние">
  <NextImage src={photo} alt="Северное сияние" fill />
</Image>
```

```tsx
<Image fit="contain" width="100%" height={160}>
  <svg viewBox="0 0 100 100" role="img" aria-label="Абстрактный знак">
    <circle cx="50" cy="50" r="40" fill="var(--accent-9)" />
  </svg>
</Image>
```

## Прелоадер

В режиме `src` скелетон появляется и скрывается сам — компонент слушает `load`/`error` нативного `<img>`. Для произвольных `children` слушать нечего, поэтому состояние загрузки задаётся явно через `isLoading`.

```tsx
<Image isLoading={!photoReady} preloader={<Loading size={32} />}>
  <NextImage src={photo} alt="Лесная тропа в тумане" />
</Image>
```

:::tip
`preloader` переопределяет скелетон целиком — передайте любой элемент, например `Loading`, если скелетон не подходит по смыслу.
:::

## Битое изображение

Если `src` не загрузился, `Image` показывает нейтральную заглушку вместо стандартной битой картинки браузера — иконку в сером круглом медиа-чипе, как у `Result`. `alt` при этом остаётся доступным читалкам экрана через `aria-label`.

```tsx
<Image src="https://broken.url/photo.jpg" alt="Фото с офсайта" />
```

## Подпись

`caption` принимает любой узел, не только строку — например, ссылку на источник. Подпись всегда выровнена по центру под кадром.

```tsx
<Image src={photo} alt="Пейзаж" caption="Источник: NASA" />
```

## Свойства

:::prop[src]{type="string"}
Ссылка на картинку. Игнорируется, если передан `children`.
:::

:::prop[alt]{type="string" default="''"}
Альтернативный текст для `<img>` в режиме `src`; также используется как `aria-label` заглушки при ошибке загрузки.
:::

:::prop[children]{type="ReactNode"}
Произвольный элемент картинки (`next/image`, `svg`, `picture`, постер видео), рендерится вместо `src`.
:::

:::prop[fit]{type="'cover' | 'contain' | 'fill' | 'none' | 'scale-down'" default="'cover'"}
CSS `object-fit`, применяемый к картинке.
:::

:::prop[objectPosition]{type="string"}
CSS `object-position`.
:::

:::prop[width]{type="number | string" default="'100%'"}
Ширина кадра. Число трактуется как пиксели.
:::

:::prop[height]{type="number | string" default="'auto'"}
Высота кадра. Число трактуется как пиксели.
:::

:::prop[radius]{type="number | string" default="'var(--radius-l)' (12px)"}
Радиус скругления кадра. Число трактуется как пиксели.
:::

:::prop[caption]{type="ReactNode"}
Подпись, отцентрированная под кадром. Принимает любой узел, не только строку.
:::

:::prop[isLoading]{type="boolean"}
Управляет прелоадером для произвольного `children` — слушать событие загрузки не у чего, поэтому состояние задаётся явно. В режиме `src` игнорируется.
:::

:::prop[preloader]{type="ReactElement" default="Skeleton"}
Переопределяет прелоадер по умолчанию.
:::

:::prop[onLoad]{type="(event: SyntheticEvent<HTMLImageElement>) => void"}
Срабатывает при успешной загрузке картинки в режиме `src`.
:::

:::prop[onError]{type="(event: SyntheticEvent<HTMLImageElement>) => void"}
Срабатывает при ошибке загрузки картинки в режиме `src`.
:::

## Рекомендации

**Не оборачивайте `next/image` или `svg` в собственный `<div>` с `overflow: hidden`.** `Image` уже задаёт кадр, `object-fit` и подпись — двойная обёртка только дублирует стили.

**Указывайте `alt` даже в режиме `children`, если внутри `<img>`.** Заглушка при ошибке и доступность строятся вокруг `alt`/`aria-label` — компонент не может достать текст описания из произвольного дочернего элемента.

**Не используйте `isLoading` в режиме `src`.** Он там ничего не делает — состояние загрузки в этом режиме компонент отслеживает сам.
