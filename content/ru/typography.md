# Типографика

[`Text`](../components/content/text) — единственный текстовый примитив в Altrone: любой размер, начертание и семантический элемент (параграф, список, ссылка) проходит через один компонент и одну общую шкалу, вместо того чтобы каждый компонент придумывал свои размеры шрифта. Эта статья — про саму эту общую шкалу: токены, которые за ней стоят, и как ими пользоваться.

## Шкала размеров

Девять уровней, каждый связывает размер шрифта с собственной высотой строки — проп `size` у `Text` выбирает один напрямую (`<Text size={7}>`):

| Size | Размер шрифта | Высота строки |
| --- | --- | --- |
| 1 | 8px | 12px |
| 2 | 10px | 14px |
| 3 | 12px | 16px |
| 4 (по умолчанию) | 14px | 20px |
| 5 | 16px | 24px |
| 6 | 18px | 26px |
| 7 | 20px | 28px |
| 8 | 24px | 30px |
| 9 | 28px | 36px |

`4` — базовый размер основного текста: именно его `Application` задаёт как корневой размер шрифта приложения, поэтому любой `Text` без явного `size` наследует его, а не откатывается на размер по умолчанию браузера.

## Начертание

Четыре токена, каждый — конкретное числовое значение веса, а не общий «bold: true/false»:

| Токен | Вес |
| --- | --- |
| `light` | 300 |
| `regular` (по умолчанию) | 400 |
| `medium` | 500 |
| `bold` | 600 |

## Шрифты

Два семейства шрифтов, у каждого — настоящий запасной стек, а не голое имя шрифта:

- **`--font-family-base`** — `Inter Variable`, затем системные sans-serif запасные варианты
- **`--font-family-code`** — `JetBrains Mono Variable`, затем универсальный моноширинный запасной вариант

`Text code` (и всё остальное, что рендерит инлайновый/блочный код) использует шрифт для кода; всё остальное — базовый.

## Размер иконки следует за текстом, а не наоборот

У иконок нет собственной независимой шкалы размеров — они следуют за размером окружающего компонента. Полное соглашение (включая класс `lucide`, к которому привязано автоматическое масштабирование в `1em`) — в статье [Иконки](icons).

## Построение собственных компонентов

1. **Обращайтесь к `Text` и шкале размеров/начертаний выше для любого текста** — никогда не вписывайте `font-size` или `font-weight` напрямую.
2. **Размер иконки следует за компонентом, а не за токеном типографики** — см. [Иконки](icons), вместо того чтобы пытаться задать размер иконки через `--text-size-*` напрямую.
