# Text

Хорошая типографика незаметна. Пользователь не думает о шрифте — он читает содержимое. `Text` — единственный компонент для работы с текстом в Altrone UI: он рендерит нужный HTML-элемент в зависимости от переданных пропов, сохраняя семантику и визуальную последовательность по всему интерфейсу.

## Варианты

`Text` использует дискриминированное объединение: один проп определяет, какой элемент будет отрендерен. Два дискриминирующих пропа одновременно — ошибка типов.

:::col-3

**Строчный** (`<span>`)

По умолчанию. Для инлайн-текста внутри параграфа: акценты, подписи, декорированные фрагменты.

```tsx
<Text>строчный текст</Text>
```

---

**Блочный** (`<p>`)

Проп `block`. Самостоятельный параграф или любой текст, которому нужен блочный контекст.

```tsx
<Text block>параграф</Text>
```

---

**Ссылка** (`<a>`)

Проп `href`. Внутренняя навигация или внешняя ссылка с автоматическим `target="_blank"`.

```tsx
<Text href="/docs">документация</Text>
<Text href="https://github.com" external>
  GitHub
</Text>
```

:::

## Масштаб размеров

Девять ступеней — от подписей до крупных заголовков. Размер не указывает на важность сам по себе: он соответствует роли текста в иерархии страницы.

```tsx
<Text size={2}>Подпись, метаданные</Text>
<Text size={3}>Вспомогательный текст</Text>
<Text size={4}>Основной текст интерфейса</Text>
<Text size={5} weight="medium">Усиленный body</Text>
<Text size={6} weight="bold">Заголовок блока</Text>
<Text size={7} weight="bold">Заголовок страницы</Text>
<Text size={8} weight="bold">Крупный акцент</Text>
```

::playground{src=TextSizeDemo caption="Размеры 2–8 в контексте типичных ролей"}

Когда `size` не указан, компонент наследует размер из каскада CSS. Это позволяет вставлять `Text` внутрь текстовых блоков, не нарушая их ритм.

## Начертание

```tsx
<Text weight="light">Light</Text>
<Text weight="regular">Regular</Text>
<Text weight="medium">Medium</Text>
<Text weight="bold">Bold</Text>
```

::playground{src=TextWeightDemo}

`light` хорошо работает на крупных размерах (7–9), где `regular` выглядел бы слишком тяжело. `medium` — универсальный акцент без агрессии. `bold` — для заголовков и данных, которые нужно выделить с первого взгляда.

## Цвет

Семантические цвета сигнализируют о смысле, а не просто создают контраст. Используйте их последовательно — пользователь запоминает значение цвета.

```tsx
<Text color="muted">Второстепенная информация</Text>
<Text color="success">Сохранено успешно</Text>
<Text color="warning">Приближается к лимиту</Text>
<Text color="danger">Ошибка авторизации</Text>
```

::playground{src=TextColorDemo}

:::tip
Не используйте `color="danger"` для декоративных целей. Красный текст — это сигнал тревоги. Если пользователь видит его там, где ничего плохого не происходит, он начинает игнорировать настоящие ошибки.
:::

## Инлайн-декорации

Декорации применяются к строчным фрагментам внутри текста. Комбинируйте их осторожно: чем больше разных стилей в одном блоке, тем сложнее понять, что важно.

```tsx
<Text italic>Курсив — для терминов и цитат</Text>
<Text underline>Подчёркивание — дополнительный акцент</Text>
<Text deleted>Зачёркнутое — удалённый или устаревший контент</Text>
<Text highlighted>Выделение фоном — визуальный маркер</Text>
<Text code>npm install altrone-ui</Text>
<Text kbd>Ctrl + S</Text>
```

::playground{src=TextDecorationsDemo}

`code` и `kbd` рендерятся моноширинным шрифтом, но несут разную семантику: `code` — для фрагментов кода и команд, `kbd` — для клавиш и сочетаний.

## Управление переполнением

Когда контейнер фиксированной ширины не вмещает весь текст, выбирайте стратегию явно — не полагайтесь на дефолтное поведение браузера.

```tsx
{/* Одна строка с многоточием — нужна ограниченная ширина */}
<Text truncate style={{ maxWidth: 240 }}>
  Очень длинное название, которое не поместится
</Text>

{/* Максимум N строк */}
<Text block lineClamp={3}>
  Длинное описание, которое обрежется после третьей строки...
</Text>

{/* Запрет переноса */}
<Text nowrap>[Regression]</Text>
```

::playground{src=TextOverflowDemo}

:::note
`truncate` требует ограниченной ширины на самом элементе или его родителе — иначе текст просто не будет обрезан. `lineClamp` работает корректно в блочном контексте.
:::

## Выравнивание

```tsx
<Text block align="start">По левому краю (по умолчанию)</Text>
<Text block align="center">По центру</Text>
<Text block align="end">По правому краю</Text>
<Text block align="justify">По ширине</Text>
```

Выравнивание имеет смысл только в блочном контексте. Для строчного `<span>` оно не даст видимого эффекта.

## Списки

Списки строятся из пары `list` + `item`. Содержимое каждого `item` поддерживает все те же пропы `Text`.

:::col-2

### Нумерованный список

```tsx
<Text list="numeric">
  <Text item>Установить зависимости</Text>
  <Text item>Настроить провайдер</Text>
  <Text item>Импортировать компоненты</Text>
</Text>
```

---

### Маркированный список

```tsx
<Text list="marked">
  <Text item>TypeScript</Text>
  <Text item>React 18+</Text>
  <Text item>Vite или Next.js</Text>
</Text>
```

:::

## Ссылки

`href` превращает `Text` в `<a>`. Проп `external` автоматически добавляет `target="_blank"` и `rel="noopener noreferrer"` — писать их вручную не нужно.

```tsx
{/* Внутренняя ссылка */}
<Text href="/docs/getting-started">Начало работы</Text>

{/* Внешняя ссылка */}
<Text href="https://github.com" external>Репозиторий на GitHub</Text>

{/* Ссылка внутри параграфа */}
<Text block>
  Подробнее в <Text href="/docs/installation">руководстве по установке</Text>.
</Text>
```

::playground{src=TextLinkDemo}

## Инлайн-композиция

Самое сильное применение `Text` — комбинирование строчных вариантов внутри одного блока. Это позволяет точечно применять стили без дополнительных обёрток.

```tsx
<Text block size={4}>
  Нажмите <Text kbd>Ctrl + S</Text>, чтобы сохранить, или выполните{" "}
  <Text code>git commit</Text> в терминале. Изменения{" "}
  <Text deleted>не будут</Text> применены немедленно —
  сначала пройдёт <Text highlighted>проверка</Text>.{" "}
  <Text href="/docs" color="muted">Подробнее →</Text>
</Text>
```

::playground{src=TextInlineCompositionDemo}

## Использование как другой элемент (asChild)

`asChild` переносит стили типографики на произвольный дочерний элемент. Полезно, когда семантика диктует один тег, а визуал — другой.

```tsx
<Text size={3} color="muted" align="center" asChild>
  <button type="button" onClick={handleLoadMore}>
    Загрузить ещё
  </button>
</Text>
```

:::note
`asChild` требует ровно одного дочернего элемента. Если `children` не является валидным React-элементом, компонент вернёт `null`.
:::

## Свойства

:::prop[size]{type="1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9"}
Шкала размеров. 1 — наименьший, 9 — наибольший. Если не указан, наследует размер из каскада CSS.
:::

:::prop[weight]{type="'light' | 'regular' | 'medium' | 'bold'" default="'regular'"}
Насыщенность шрифта.
:::

:::prop[color]{type="'success' | 'danger' | 'warning' | 'muted'"}
Семантический цвет. Если не указан, наследует цвет из контекста.
:::

:::prop[align]{type="'start' | 'center' | 'end' | 'justify'"}
Выравнивание текста. Работает только в блочном контексте.
:::

:::prop[italic]{type="boolean" default="false"}
Курсивное начертание.
:::

:::prop[underline]{type="boolean" default="false"}
Подчёркивание.
:::

:::prop[deleted]{type="boolean" default="false"}
Зачёркивание. Обозначает удалённый или устаревший контент.
:::

:::prop[highlighted]{type="boolean" default="false"}
Выделение фоновым цветом.
:::

:::prop[code]{type="boolean" default="false"}
Моноширинный стиль для фрагментов кода и команд.
:::

:::prop[kbd]{type="boolean" default="false"}
Стиль клавишной подсказки для горячих клавиш и сочетаний.
:::

:::prop[truncate]{type="boolean" default="false"}
Однострочное усечение с многоточием. Требует ограниченной ширины на элементе.
:::

:::prop[lineClamp]{type="number"}
Многострочное усечение. Ограничивает количество видимых строк.
:::

:::prop[nowrap]{type="boolean" default="false"}
Запрещает перенос строки (`white-space: nowrap`).
:::

:::prop[block]{type="boolean"}
Рендерит `<p>`. Взаимоисключает с `href`, `list`, `item`, `asChild`.
:::

:::prop[list]{type="'numeric' | 'marked'"}
Рендерит `<ol>` или `<ul>`. Требует вложенных `<Text item>`.
:::

:::prop[item]{type="boolean"}
Рендерит `<li>`. Используется только внутри `<Text list>`.
:::

:::prop[href]{type="string"}
URL. Рендерит `<a>`.
:::

:::prop[external]{type="boolean" default="false"}
Добавляет `target="_blank" rel="noopener noreferrer"`. Только для `href`-варианта.
:::

:::prop[asChild]{type="boolean"}
Объединяет стили типографики с дочерним элементом через паттерн Slot.
:::

## Рекомендации

**Не создавайте смысл через размер.** Большой текст не значит важный — важный текст сообщает что-то существенное. Выбирайте размер по роли в иерархии, а не по ощущению значимости контента.

**Ограничьте палитру на экран.** Два-три размера, два-три веса. Каждое отклонение от базового стиля должно нести смысл. Если разнообразие стилей на странице требует усилий для восприятия — это слишком много.

**Семантические цвета — для семантики.** `danger` — только для ошибок. `success` — только для подтверждений. Использование этих цветов в декоративных целях обесценивает их как сигналы.

**Используйте `block` осознанно.** Строчный `<span>` по умолчанию — это намеренное решение. Переключайтесь на `block` тогда, когда текст является самостоятельным параграфом, а не частью потока.

**`truncate` — не замена верстки.** Если текст обрезается всегда — стоит пересмотреть структуру, а не скрывать проблему многоточием. Усечение оправдано там, где длина заранее непредсказуема: имена файлов, пользовательский ввод, данные из API.
