# Popover

:::release[Altrone 4 Decent Dragon]{icon="/logos/altrone-4.png" logo="Popover" name="Popover" open="true"}
**4.0**

- Новый дизайн.
- Новая анимация появления.
- Улучшено позиционирование.
- Добавлен режим отображения поверх компонента-источника (`overlap`).
- Убрана встроенная стрелка.
- `ref` теперь указывает на DOM-элемент триггера.
- Императивный API (`show`/`hide`, ранее `openPopup`/`closePopup`) переехал в `controlRef`.
- Добавлен управляемый режим `open`/`onOpenChange`.
:::
