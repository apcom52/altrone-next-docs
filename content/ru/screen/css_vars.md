# Screen

CSS-переменные `Screen`, которые можно переопределить. Они задают ширину бокового меню и боковой панели, высоту закреплённых панелей, а также ширину и отступы содержимого.

:::spoiler[Как переопределять переменные]
Самый надёжный способ — проп `style` того элемента, которому принадлежит переменная: значение, заданное прямо на элементе, перебивает всё остальное. Большинство переменных используется на всём экране, поэтому задавайте их на `Screen`:

```tsx
<Screen
  style={{ '--screen-sidebar-width': '260px' } as React.CSSProperties}
>
  {/* areas */}
</Screen>
```

Для трёх переменных есть пропы, которые задают их за вас: `sidebarWidth`, `asideWidth` и `maxWidth` у `Screen.Content` (плюс `size`). `--screen-header-inset-start` задаётся пропом `insetStart` у `Screen.Header` и имеет смысл только на шапке. Если проп есть, лучше использовать его.

`--screen-header-height` и `--screen-bottom-nav-height` задают размер закреплённых панелей и место, которое под них оставляет содержимое. Панель инструментов внутри шапки сама не подстраивается, поэтому меняйте её `size` вместе с высотой шапки.

Что переопределить нельзя:

- **`--top-safe-area` и `--bottom-safe-area`.** `Screen` вычисляет их по шапке и нижней панели. Читайте их, чтобы разместить свои залипающие элементы (`top: var(--top-safe-area)`), но не задавайте.
- **Общую линию содержимого** (`--screen-content-inset-start`) и место, оставленное под боковое меню. Они складываются из ширины меню и отступа содержимого; изменение любого из них собьёт выравнивание шапки, содержимого и подвала.
- **Вертикальные отступы подвала.** Они жёстко равны трём `--space-content` (плюс нижняя безопасная зона). Менять можно только переменную отступа содержимого ниже.
:::

## Внутренние переменные

Определяются самим `Screen`.

::::css-vars
:::css-var[--screen-sidebar-width]{kind="size" type="Размер"}
Ширина бокового меню рядом с содержимым. По умолчанию: `300px`
:::

:::css-var[--screen-aside-width]{kind="size" type="Размер"}
Ширина боковой панели в сетке страницы. По умолчанию: `320px`
:::

:::css-var[--screen-header-height]{kind="size" type="Размер"}
Высота шапки и место, оставленное под неё. По умолчанию: `56px`
:::

:::css-var[--screen-bottom-nav-height]{kind="size" type="Размер"}
Высота панели нижней навигации. По умолчанию: `64px`
:::

:::css-var[--screen-content-max-width]{kind="size" type="Размер"}
Максимальная ширина колонки содержимого. По умолчанию: `none`
:::

:::css-var[--screen-content-padding-block]{kind="gap" type="Размер отступа"}
Отступ сверху и снизу у содержимого и боковой панели. По умолчанию: `calc(var(--space-content) * 2)`
:::

:::css-var[--screen-header-inset-start]{kind="gap" type="Размер отступа"}
С какого места начинается содержимое панели инструментов шапки. По умолчанию: выровнено по `Screen.Content`
:::
::::

## Глобальные переменные

`Screen` их не определяет: это общие токены, которые он использует для отступов, поверхностей и слоёв. Изменение токена перекрашивает все экраны сразу.

::::css-vars
:::css-var[--space-content]{kind="gap" type="Размер отступа"}
Отступ вокруг бокового меню и нижней панели и боковой отступ содержимого. По умолчанию: `var(--gap)`
:::

:::css-var[--xs-gap]{kind="gap" type="Размер отступа"}
Небольшой дополнительный запас, добавляемый к отступам безопасных зон. По умолчанию: `4px`
:::

:::css-var[--background-2]{kind="fill" type="Цвет заливки" color="var(--background-2)"}
Заливка подвала. По умолчанию: `var(--gray-2)`
:::

:::css-var[--border-1]{kind="border" type="Цвет обводки" color="var(--border-1)"}
Тонкая линия над подвалом. По умолчанию: `var(--gray-6)`
:::

:::css-var[--color-overlay-scrim]{kind="fill" type="Цвет заливки" color="var(--color-overlay-scrim)"}
Затемнённый фон за боковым меню, когда оно открывается поверх содержимого. По умолчанию: `var(--black-a3)`
:::

:::css-var[--level-fixed]{kind="size" type="Слой"}
Слой бокового меню и нижней панели; шапка находится на уровень ниже. По умолчанию: `1030`
:::

:::css-var[--level-offcanvas-backdrop]{kind="size" type="Слой"}
Слой затемнённого фона за боковым меню. По умолчанию: `1040`
:::

:::css-var[--elevation-overlay-z-index]{kind="size" type="Слой"}
Слой бокового меню, когда оно открывается поверх содержимого. По умолчанию: `var(--level-popover)`
:::

:::css-var[--breakpoint-xs]{kind="size" type="Размер"}
Предел ширины содержимого для `size="mini"`. По умолчанию: `520px`
:::

:::css-var[--breakpoint-sm]{kind="size" type="Размер"}
Предел ширины содержимого для `size="s"`. По умолчанию: `768px`
:::

:::css-var[--breakpoint-md]{kind="size" type="Размер"}
Предел ширины содержимого для `size="m"`. По умолчанию: `1024px`
:::

:::css-var[--breakpoint-lg]{kind="size" type="Размер"}
Предел ширины содержимого для `size="l"`. По умолчанию: `1280px`
:::

:::css-var[--breakpoint-xl]{kind="size" type="Размер"}
Предел ширины содержимого для `size="xl"`. По умолчанию: `1640px`
:::
::::
