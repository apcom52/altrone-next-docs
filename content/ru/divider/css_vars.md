# Divider

CSS-переменные, которые читает `Divider` и которые можно переопределять.

:::spoiler[Как переопределить переменные]
`--divider-color` задана на корне приложения, поэтому проп `style` у `Divider` — надёжный способ изменить её для одной линии: значение в нём сильнее значения по умолчанию.

```tsx
<Divider style={{ "--divider-color": "var(--accent-9)" } as React.CSSProperties} />
```

::playground{src=divider/DividerCssVarsDemo caption="Линия акцентного цвета"}

Толщина (`1px`) и скругление концов фиксированы и через переменные не меняются. Отступ от краёв контейнера и внешние отступы берутся из глобальных `--l-gap` и `--xs-gap`; внутри `Flex` с `disableInnerMargins` по умолчанию внешние отступы обнуляются, и расстояние задаёт `gap` у `Flex`.
:::

## Внутренние переменные

Определены самим компонентом.

::::css-vars
:::css-var[--divider-color]{kind="fill" type="Цвет заливки" color="var(--border-a1)"}
Цвет линии. По умолчанию: `var(--border-a1)`
:::
::::

## Глобальные переменные

Не определены самим компонентом, но влияют на его вид.

::::css-vars
:::css-var[--border-a1]{kind="fill" type="Цвет заливки" color="var(--border-a1)"}
Значение по умолчанию для `--divider-color`. По умолчанию: `var(--gray-a6)`
:::

:::css-var[--l-gap]{kind="gap" type="Отступ"}
Насколько горизонтальная линия короче контейнера; боковые отступы вертикальной линии. По умолчанию: `12px`
:::

:::css-var[--xs-gap]{kind="gap" type="Отступ"}
Верхний и нижний отступы линии. По умолчанию: `4px`
:::
::::
